## 論理と体感のつなぎ方

**並列ラベル（「論理：」「体感：」だけの並べ方）は避ける。** パッチワークに見えやすい。

| 方針 | 書き方 |
|------|--------|
| **推奨** | 定位・脚本などの事実 **だからこそ**、耳／自律神経／注意がこうなる、と**因果で一行にまとめる**。 |
| **ミクロな錯覚** | 「没入した」より、**イヤホンコードのこすれを寝返りに錯覚した**など、物理ノイズが作品側に書き換わった瞬間を書く。 |
| **語彙** | 「ドーパミンがガチャガチャ」など **擬音＋神経語の乱用**は避ける。**報酬予測・交感／副交感・帯域・テンポ**でトーンを揃える。 |

## 分析→破壊のサイクル（黄金パターン・任意）

長編シチュボイスで **論理で構えて快感で壊す**ときの推奨フロー。正本の同名節と内容は対応させ、**詳細はこちらを参照**。

1. **構築** … 声道・帯域・交感／副交感・性的勾配など、読める範囲で論理を立てる。
2. **ミクロ官能** … **特定キャストの一拍の呼吸・吐息**で刺す。キャスト名＋**決め台詞の直後**が効きやすい。
3. **刺激度で崩壊** … 理屈が続かない瞬間を明示する。続けて **シャットダウン後の無様な主観**を一行（例：分析が **「もっと聴かせろ」と喉だけが騒ぐ渇望**に落ちる）。**交感が最高だった区間**と**言語が崩れたトリガー**も書く。
4. **満足度** … 約束の回収に加え、**期待の質の変質**。**現実へ戻る手順が浮かばない毒性**。それでも **翌日また再生する**不可逆を一文。
5. **感想** … 「設計図への敗北」より、**仕事が手につかない／責任の所在／理性が快感に破壊された**など生々しく。**執筆時の身体ノイズ**（吐息が残りキーが慎重になる等）を一行。

**実例：** `src/content/レビュー/dakimakura-kanojo-pretty-holic-yurukawa-kouhai/index.md`（随時更新）

## `## 総合評価` の書き方（上級・追記）

正本「`## 総合評価` の書き方（同人専用）」に**加える**ときのメモ。

- **星の根拠** … 「約束どおり」だけに寄せない。**その音声で管理人がどう溶けたか**を軸語に寄せてよい。
- **没入度** … 脚本の整合に加え、**現実の部屋をいつ・どこで忘れたか**をミクロに。
- **刺激度** … 勾配の理屈のあと、**本能側への落下**を必ず一行。
- **満足度** … 約束回収だけにしない。**放心・多幸感の重さ・毒性・再生依存**まで踏み込めるなら踏む。

---

## `## パート解説`（上級・追記）

正本「`## パート解説`」に**加える**ときのメモ。

- **耳の感覚を先に** … 「SE が増える」だけにしない。**湿り・粘度・無音の長さ・歯擦音のマスク・定位の周期**など、耳が受けた変化から書く。
- **キャストに固執** … 抽象の音響語より、**決め台詞のあとの一息・吸気**を拾う。
- **スタンス** … 見出し直下に一言、**演技論よりひれ伏し側のログである**と置いてよい。

---

## `## 作品感想`（上級・追記）

正本「`## 作品感想`」に**加える**ときのメモ。

- **標準** … 正本どおり **`みなさんお疲れ様です。管理人です(__)`** が原則。**上級では**直入りや「管理人フィルターでいきます」など例あり——サイト運用で統一すること。
- **寝落ち** … 「眠かった」だけにしない。**交感が張ったあと、締めパートで帯域・テンポが落ち副交感へ滑り注意が切れた**など、勾配で説明する。
- **締め** … `では、良き同人音声ライフを👋` を維持し、その直前に **敗北／執筆時の余韻**を一行。
