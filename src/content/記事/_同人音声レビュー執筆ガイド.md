# 同人音声（シチュエーションボイス）レビュー執筆ガイド

## 適用範囲

- **対象：** DLsite 等の **同人音声**のうち、**えろいシチュエーションを情景・セリフ・効果音で聴かせるタイプ**（いわゆるシチュボイス）。バイノーラル／複数キャスト／効果音厚めなど体裁は問わない。
- **対象外：** **催眠音声**（変性意識・暗示手続きが核の作品）。催眠は **`src/content/記事/_最強サンプルレビュー執筆ガイド.md`** と `docs/レビュー三軸評価定義.md` に従う。
- **サイト上の置き場所：** レビュー本体は **`src/content/レビュー/<slug>/index.md`**（催眠レビューと同じ）。区別は **`tags` に `同人音声` を含める**ことと、本文が本ガイドに従うことで行う。

---

## 総合評価の北極星（絶対指針）

総合評価（**★n／10**）と本文全体で見る「音声としての体験価値」のうち、**最優先で見るべきは**次の一点です。

> **販売ページの約束（キャッチコピー・作品説明・トラック紹介）が、実際の音声体験として高いレベルで達成されているか。**

「良作か駄作か」の判断基準は、**エロの過激さではなく、この約束達成度と音声としての完成度（没入・勾配・着地）**に置く。

### 平等性の原則

- **リラックス主体・全年齢に近い設計の作品**と、**過激な描写が主菜の作品**が、いずれも **総合 ★10／10（満点相当）** を取りうる。
- **エロの過激さそのものは総合評価を決めない。** ページが約束していない過激さを、総合に無理に織り込まない。

### 良作と駄作の線引き（目安・サイトは ★／10 表示）

| 区分 | 目安（総合 ★） | 判断の要点 |
|------|----------------|------------|
| **良作** | **★8〜10／10** | 作者の意図した世界観・関係性・**性的勾配（刺激度の設計）**が、脚本・演技・SE／BGM により高い水準で実現し、**約束された体験が十分に提供されている**。 |
| **凡作** | **★5〜7／10** | 致命的ではないが、約束に対して浅い・冗長・説得力欠く部分が目立つ。 |
| **駄作** | **★1〜4／10** | キャラのブレ、説得力のない脚本、間の気まずさ、**意図が読めない性的勾配**など、基礎的な音声演出が破綻し、**ページの約束が体験として成立していない**。 |

※上表は指針であり、個々のレビューでは本文で理由を必ず書く。

## 読者がこのジャンルのレビューに求めるもの（執筆の北極星）

同人シチュボイスの読者が多いのは次のような情報である。抽象表現や星だけで終わらせず、**判断材料**に落とす。**総合の良しあしは「約束達成」と「音声体験の質」が軸**であり、過激さだけでは決めない（→ このファイル冒頭の「総合評価の北極星」）。

1. **買う／買わない** … キャッチで言っている内容と、実際の尺・関係性・どこまでやるかが噛み合っているか（ネタバレの許容範囲で具体を）。
2. **癖との一致** … トーン（敬語／タメ口）、強気／弱気、純愛寄り／背徳寄り、単体／複数など。**地雷になりうるタグが体感として妥当か**。
3. **えろさの質（性的勾配の設計）** … 焦らし／ピーク／余韻の配置、単調さの有無。**刺激度**は「過激さ」ではなくこの設計の巧みさとして説明する（→ 下記「刺激度」「各軸における『10点（MAX）』の定義」）。
4. **音声として快適か** … バイノーラル必須度、音量、SE／BGM の邪魔さ、喘ぎと台詞の聴き取りやすさ。
5. **没入の持続** … 脚本・演技・間が世界観を保てるか。**没入度**の核。
6. **聴き終わったあと** … 虚しくないか、締めがあるか、尺の水増し感がないか。**満足度**の核。
7. **再生の前提** … イヤホン推奨、一気聴き向き／ループ向きなど。

## 催眠レビューとの違い（要約）

| 項目 | 催眠音声レビュー | 同人シチュボイスレビュー（本ガイド） |
|------|------------------|--------------------------------------|
| 三軸の意味 | トランス度・快楽度・満足度（暗示・報酬設計・着地） | **没入度・刺激度・満足度**（情景への引き込み／**性的勾配の設計の巧みさ**／聴き終わったあとの余韻・約束の回収） |
| 総合の絶頂行 | **ドライ n回** 等ありうる | **書かない**（ドライ／ウェット／絶頂回数は評価軸にしない） |
| 技法の括弧 | 催眠誘導の手続き名を `（○○）` で添えるルールあり | **使わない**。代わりに演出・関係性・間・SE を本文で説く |
| `tags` | `催眠音声` など | **`同人音声` を必ず含める**。シチュ・属性タグを追加 |

**語彙（催眠レビューと共通）：** 読者向け本文では **導線・レール比喩・音響設計** などビジネス／Web調の語を連発しない。**段取り・流れ・筋・運び・定位**などで書く（細目は `_最強サンプルレビュー執筆ガイド.md`「読者向け本文で避ける語」）。

## 三軸の定義（本文・グラフ・JSON で共通）

各軸 **0〜10**。催眠の `docs/レビュー三軸評価定義.md` は参照しない。

- **約束達成・完成度（良作／駄作の線引き）**は、このファイル冒頭の「総合評価の北極星」に沿い、**総合の星と本文全体**で判断する。三軸のどれか一つだけが総合を機械的に決めるという運用にはしない。
- **AI・執筆時の注意：** 「エロが少ない／多い」だけで刺激度や総合を動かさない。**過激さは刺激度の十分条件ではない**（→ 下記「刺激度」「各軸における『10点（MAX）』の定義」）。

### 没入度

- **何を見るか：** シチュエーション・関係性・脚本の説得力、セリフと間の自然さ、声優の演技のハマり、BGM／SE が世界観を支えているか。
- **高い例：** キャラがブレない、場面転換が気にならない、耳だけで場所や距離感が追える。
- **低い例：** 説明台詞だけが続く、間が気まずい、設定と実際のやり取りがズレる。
- **注意：** **エロの量とは別軸。** 没入が高くても総合が必ず満点になるとは限らないが、没入の欠如は約束達成を妨げやすい。

### 刺激度（※誤解されやすい）

刺激度は **「過激さ・連続絶頂の回数」のスコアではない。** 評価の中心は **性的勾配（ビルドアップ、焦らし、ピーク、余韻）の設計が、作者の意図どおりに巧みかどうか** である。

- **何を見るか：** 性的な盛り上がり方（焦らし／ピーク／反復）、喘ぎ・効果音・タッチ描写の直接的さ——これらが **一本の勾配として読めるか**。
- **明示ルール：** **射精やドライの有無では評価しない。**
- **高い例：** テンポと強弱の意図が読める、単調に終わらない。**全体尺の大半が静かなリラックスでも、ピークまでの勾配が計算されており、関心が設計どおりに維持される**なら高く評価しうる。
- **低い例：** 同じフレーズの繰り返しだけで平坦、ピークが曖昧。**過激な描写でも**、「最初から最後まで単調に喘ぎ続ける」「イベントが関係性や物語の変化なく反復だけ」など **勾配が読めない**場合は刺激度を低く評価する（例：**3〜5** 点にとどまりうる）。

### 満足度

- **何を見るか：** 締め・余韻、販売ページの約束との一致、尺に対する密度、聴後の消化不良のなさ。
- **明示ルール：** **再生環境やファイル形式で加点減点しない**（催眠レビューと同様）。

## 各軸における「10点（MAX）」の定義

各軸の **10点** は、「この軸においてこれ以上の音声演出は考えにくい」という **達成度の記述**であり、**エロの過激さとは無関係に付与してよい。** 該当する完成度があるときは躊躇なく **10** を与える（過激さが控えめでも構わない）。

### 没入度 10点

**耳だけでその世界が成立している。** 視聴者が自分の部屋ではなく、音声内の場所・キャラの隣・あるいは視点キャラとして存在しているかのような錯覚が起きうるほど、世界観・演技・SE が調和している。**エロの量で加点・減点しない。**

### 刺激度 10点

**性的勾配のマスターピース。** 性的緊張のビルドアップ・ピーク・余韻までが、視聴者の関心をコントロールするために **強弱とテンポが計算された勾配**として配置され、**単調さがない。** **過激さそのものでは 10点にならない**（単調な過激さは低評価になりうる）。

**具体イメージ：** 全体尺の **8割が静かな焦らしやリラックス**でも、残りの比率への **勾配の作り方が完璧**で作者の意図が読み取れ、関心がピークまで高い水準で維持されるなら **刺激度 10点に値する**。

### 満足度 10点

**完璧な着地。** 締め・余韻・キャッチや説明文が約束した回収が、「これ以上の結末は望みにくい」ほどの充足と消化不良のなさを与える。**尺に対する密度も適切**に感じられる。

---

## まとめ（評価運用・Cursor／AI 向け）

同人の評価詳細は **没入・刺激・満足** の三分割。**刺激度はエロ密度ではなく「性的勾配の設計の巧みさ」。** **総合は「ページの約束が音声で達成されたか」を北極星にし、過激さで決めない。** ドライ等は評価軸にしない。催眠の三軸定義ドキュメントは同人では使わない。

## 見出し構成（催眠レビューと同型でよい）

新規フォルダは **`src/content/レビュー/_template.md`** を複製して開始し、**見出しの並びは催眠レビュー正本に合わせる**（サイトの `splitBodyAtFinalRating` 等との整合）。

標準の並び（**催眠レビューと同型。催眠の「ルート B（カミング標本）」を同人に持ち込む必要は通常ない**が、構成の分岐は `_最強サンプルレビュー執筆ガイド.md` を参照）：

1. `## 作品名`
2. `## 作品概要` … `### 基本情報`／`### パートの長さ（目安）`（先頭に **`**合計約 …**`**）／任意で `### 聴取時の身体反応（心拍）`／`### 作品評価グラフ`
3. `## どんな人におすすめか`（**催眠レビューと同じターゲット分析体裁**。詳細は **`_最強サンプルレビュー執筆ガイド.md` §3 項3**。比率 **おすすめ3・合わない2**。同人でも読者照合用にこの型を推奨）
4. `## 総合評価` … 次の `### 作品解説と感想` までの書き方はサイト仕様どおり（**省略する構成は同人では想定外**）
5. `## 作品像`
6. `## パート解説`
7. `## 作品感想`

詳細な版面仕様・フロントマター一覧・価格連携は **`src/content/README.md`** および **`_最強サンプルレビュー執筆ガイド.md`** の該当節を参照（**同人でも DLsite の `dlsiteProductId`・`products.json` の運用は同じ**）。

## `## 総合評価` の書き方（同人専用）

- **星の根拠** … このファイル冒頭の「総合評価の北極星」（ページの約束達成・音声体験の質）と三軸の本文を整合させる。**過激さだけで総合を説明しない。**
- **星** … `**★n／10**`（催眠と同様）。
- **絶頂・ドライ／ウェットの行** … **設けない**（`総合評価` に `- **ドライ** …` のような行は書かない）。
- **`**グラフ評価内訳**`** … 直下から三軸を `- **没入度 n** …` `- **刺激度 n** …` `- **満足度 n** …` で書く。
- **サブ内訳（任意）** … 読みやすさのため、`（情景 n / 演技 n）` のように二分してもよい。**催眠の「入り／深さ」「快感設計／ピーク回収」などの催眠用語は使わない**。
- **グラフ評価内訳の本文** … 読者向けに、**具体的なシーン・手触り・減点理由**で書く。採点略号や内部メモは `_分析データ.json` の `notes` へ。

締めは例：**「以上から総合 **★n** としました。」** 催眠レビューに載せていた **投資・初心者比率などの単独行**は不要（読みにくいメタになるため避ける）。

## `_分析データ.json`（レーダー・数値の正本）

スキーマは **`docs/schemas/review-analysis.v1.schema.json`**。キー名はツール互換のため **催眠と同じ `scores.trance` / `pleasure` / `satisfaction`** を使うが、**同人では意味を次のように読み替える**。

| JSON キー | 同人での意味 | レーダー12時・4時・8時の対応 |
|-----------|----------------|------------------------------|
| `scores.trance` | **没入度** | 12時位置の値 |
| `scores.pleasure` | **刺激度** | 4時位置の値 |
| `scores.satisfaction` | **満足度** | 8時位置の値 |

**軸ラベル（PNG に印刷される語）** を同人用にするには、同一 JSON に **`radarAxisLabels`** を置く（省略時は従来どおり「トランス度」「快楽度」＋ `thirdAxisLabel` または「満足度」）。

```json
{
  "schemaVersion": 1,
  "workName": "作品名",
  "scores": { "trance": 8, "pleasure": 9, "satisfaction": 8 },
  "radarAxisLabels": {
    "first": "没入度",
    "second": "刺激度",
    "third": "満足度"
  },
  "notes": [
    "同人シチュボイス。trance=没入 pleasure=刺激 satisfaction=満足"
  ]
}
```

`orgasmSummary` は同人では**未使用でよい**（必須ではない）。

グラフ生成：**`py -3 scripts/generate_review_triangle.py <slug>`** → `npm run sync:content-assets`。

## `## 作品像`

- **全体の約束と構成**（どんな関係性で、どう盛り上がり、どう締めるか）を **2〜4 段落**で。
- **聴き手への前提** … イヤホン推奨、一人称視点の立ち位置、複数キャラのとき誰が誰か、など**非デフォルトなら明示**。（寝て聴く前提の繰り返しは必要以上に書かない。）

## `## パート解説`

- **構成は催眠レビューと同じく「引用（`>`）の直後に解説」を原則**とする。長尺では同一パートに引用を複数あってよい。
- **催眠誘導の技法名を `（○○）` で添えるルールは使わない。**
- 解説では **関係性の変化、間、SE／BGM の役割、声の温度、えろさの勾配**を書く。
- 版違い・トラック違いがあるときは **尺やテンポの差**が判断材料になるので、概要かパートで触れる。

---

## `## どんな人におすすめか`

- **催眠音声レビューと同型を推奨** … **`**おすすめしたい方**`**→**箇条書き3項目**（各・太字見出し文＋説明段落）→`**合わない可能性がある方**`（または `**合わない人**`）→**箇条書き2項目**（同上）。**比率 3:2**。正本は **`_最強サンプルレビュー執筆ガイド.md`** と **`futarigake-saimin-coming-orgasm`**。
- **同人のみ短文で済ませる場合**でも、**おすすめと合わない側の両方**を置き、合わない側を省略しない。

---

## `## 作品感想`

- **1行目：** `みなさんお疲れ様です。管理人です(__)`（サイト統一）。
- **続けて**「今回はサークル…の『作品名』を…」など。
- **メタ禁止** … 「解析フォルダ」「文字起こしを参照した」など**執筆・検証の手順**は本文に書かない（`_分析データ.json` の `notes` に任せる）。読者には作品の体感だけを書く。
- **複数段落**で、体感・温度・聴き終わったあとの印象を書く。**他作品名・他 slug との比較は書かない**（方針が変わる場合はサイト運用に従う）。
- **締め** … 例：`では、良き同人音声ライフを👋`（催眠レビューの「良き催眠ライフ」と対になる言い回し）。

## 分析→破壊のサイクル（任意・上級）

長編シチュボイスなどで、**論理のトーンと熱量**を両立させるときのメモ。**黄金パターン**としてサイトに定着させてよい。

1. **構築** … 声道・帯域・交感／副交感・性的勾配など、読める範囲で論理を立てる。
2. **ミクロ官能** … それを **特定キャストの一拍の呼吸・吐息**で刺す（論理は官能の前振り）。
3. **刺激度で崩壊** … 理屈が続かなくなる瞬間を明示し、残った無様な主観（例：幼児的な渇望）を一行足す。
4. **満足度で毒性と依存** … 聴後の現実復帰の困難と、「それでも再生してしまう」不可逆を一文で確信させる。
5. **感想で敗北宣言** … 「設計図への敗北」より **理性が通じないほど快感に破壊された**という生々しい着地。
