| **手順** | `手順どおり` `解除手順` `誘導手順` `回収手順` `手順的` | **流れ**・**進め方**・**段階**・**順番**・**想定どおり** |
| **積み** | `積み上げ` `積み重ね` `を積み` | 重ねる・段階的に・連続で |

| **ほどく** | `ほどきたい` `ほどけ` | 外す・緩む・戻す |
| **固定** | `〜へ固定` `先に固定` `固定し続ける` `注意を固定` | 結び付ける・先に示す・深さが続く・意識を寄せる（**表内 `【没入固定】` ラベルのみ可**） |

## 作品感想（workImpressionParagraphs）追加

- **構成は毎回変える**（「特徴だと感じました → 初回は〜 → 解除まで〜」の固定3段禁止）
- **文体** … 解析室レビュアーの**生きた所感**（§8.4 正本・**AI調排除・忖度無し**）。解説カタログ・全段落称賛・`でしょう` 連発・グリム型決まり文句の使い回し禁止
- **忖度無し** … 総合★・三軸と矛盾する褒め禁止。★8以上も弱点**1文以上**。★7以下は短所段落必須（見本C: `saimin-shinri-test-dame-iwakareru`）
- **AI調** … 「続きました」「寄せてくれます」「約束どおり」「満足感が得られると思います」だけの称賛連打禁止。`index.md` 本文の言い換えだけは不合格
- **サークル名・声優名（CV）禁止** … `workImpressionParagraphs` 全文に **サークル名・声優名・「○○氏」・サークル略称** を書かない。語り手は「語り手」「この声」「語りかけ」等で指す（`voiceActor`・`circleName`・tags・基本情報 CV は別フィールド）
- **点数・採点禁止** … **★・三軸名・数値（7.5 / 4.2 等）・「総合★9」「トランス10」** を書かない。弱点は体感・場面で書く（グラフ・`scoreLabel` は別表示）
- 禁止の書き出し: `聴き終わった印象としては` `この作品いちばんの特徴だと感じました`（1本1回まで）

## ドライオーガズムと脳イキ

- **別物。** `ドライオーガズム（脳イキ）`・同一視禁止。台本がドライなら絶頂の主語はドライオーガズム。

## 【合わない可能性がある人】（§0.3）

- **時間／尺を理由にしない** … ラベル・理由・`notRecommendedFor` すべて。**`短時間で完結させたい方` は禁止**（代表例）。
- **快感欲求ラベルを立てない** … **`すぐに快感を求めたい方`** **`快感を急いでほしい方`** 等、リスナーが「快感を先に／急に」欲する像を合わない理由にしない。理由も **`すぐに絶頂へ`** **`じれったい`** **`深化に時間をかける`** 等の早さ・欲求主語を避ける。
- 代用 … **誘導・トーン・刺激の相性**（例: `穏やかな催眠誘導だけを好む方`／単線誘導を好む／矛盾文が苦手／ドライ中心が合わない）。
- 尺の事実は `### 梱包ファイル`・`recording` へ。合わない判定の根拠にしない。
- **見本をコピーしてもこの禁止は解除されない**（本書ルール最優先）。

## 【合わない】全年齢同人（`tags: 全年齢同人`）

- **性描写の有無**を合わない理由にしない … `直接的な性的描写を期待する方` `露骨な性的描写` `肉体的な刺激を求める方` 等（**R18 前提の当たり前**）は禁止。
- 代用 … **作風・シチュ**／**刺激・音像・テンポ**の不一致。正本: `docs/全年齢シチュエーションボイス執筆ガイド.md` §5.1。
- **クイック `notRecommendedFor`** も同様（ラベルのみ・理由は `index.md`）。
