# 読者向け散文 — 禁止語（Gemini 執筆・改稿共通）

**正本:** `docs/催眠音声執筆ガイド.md` §7.1・§8.4 ／ `.cursor/rules/review-prose-voice.mdc`  
**適用:** `[KEY]` ブロック全文・`workImpressionParagraphs`・グラフ評価内訳。**台詞引用（`> ` 行）のみ例外**。

## 必ず禁止（出力前に自己チェック）

| 語 | 例（NG） | 代用 |
|---|---|---|
| **芯** | `この作品の芯` `快感の芯は` `芯だと感じました` | 特徴・肝・要・〜が目立つ |
| **手順** | `手順どおり` `解除手順` `誘導手順` `回収手順` `手順的` | **流れ**・**進め方**・**段階**・**順番**・**想定どおり** |
| **積み** | `積み上げ` `積み重ね` `を積み` | 重ねる・段階的に・連続で |
| **立ち上が** | `立ち上がり` `立ち上がる` | 高まる・強まる・早まる |
| **ほどく** | `ほどきたい` `ほどけ` | 外す・緩む・戻す |
| **固定** | `〜へ固定` `先に固定` `固定し続ける` `注意を固定` | 結び付ける・先に示す・深さが続く・意識を寄せる（**表内 `【没入固定】` ラベルのみ可**） |
| **設計** `導線` `密度` `主軸` | 論文・AI語 | 流れ・組み立て・狙い（必要最小限） |

## AI調（総評三柱・読者向け散文・必須）

**抽象語を重ねて「高い」と言うだけの文は禁止。** 快感・没入は **場面・身体感・台本の動き** で書く。

| 語句（NG） | 代用 |
|---|---|
| **上位帯の厚み** `上位帯で高まります` | 快感の起伏が深い／胸の奥まで熱が溜まる／終盤で全身へ返る落差 |
| **融合と重なり** | 背徳と安心が同時に続く／〜が重なる（1要素に限定） |
| **畳みかけとして** | 順に追い込む／カウントで落差を返す |
| **体験を提供します** **成功した体験** | 聴き終わったあとに残る／着地が〜 |
| **多角的に組み合わせ** **緻密な構成が特徴** | たこ焼き化から触手責めまで一本の流れ／〜から〜へ順に |

※ **`上位帯` 単体**（`上位帯の快楽密度` 等・§5.1）は可。**`上位帯の厚み`** は不可。監査: `review_prose_rules.py` の `AI_PHRASE_PATTERNS`。

## 作品感想（workImpressionParagraphs）追加

- **構成は毎回変える**（「特徴だと感じました → 初回は〜 → 解除まで〜」の固定3段禁止）
- **文体** … 解析室レビュアーの**生きた所感**（§8.4 正本・**AI調排除・忖度無し**）。解説カタログ・全段落称賛・`でしょう` 連発・グリム型決まり文句の使い回し禁止
- **忖度無し** … 総合★・三軸と矛盾する褒め禁止。★8以上も弱点**1文以上**。★7以下は短所段落必須（見本C: `saimin-shinri-test-dame-iwakareru`）
- **AI調** … 「続きました」「寄せてくれます」「約束どおり」「満足感が得られると思います」だけの称賛連打禁止。`index.md` 本文の言い換えだけは不合格
- **サークル名・声優名（CV）禁止** … `workImpressionParagraphs` 全文に **サークル名・声優名・「○○氏」・サークル略称** を書かない。語り手は「語り手」「この声」「語りかけ」等で指す（`voiceActor`・`circleName`・tags は別フィールド）
- **例外：`### 基本情報` の声優／CV 行のみ「氏」必須** … DLsite CV 名の直後に **氏**（例：`エトラ氏`）。VTuber 補足括弧は氏の後。**グラフ・総評・summary 等の本文では氏も声優名も従来どおり**（`docs/催眠音声執筆ガイド.md` §0.1.4）
- **点数・採点禁止** … **★・三軸名・数値（7.5 / 4.2 等）・「総合★9」「トランス10」** を書かない。弱点は体感・場面で書く（グラフ・`scoreLabel` は別表示）
- 禁止の書き出し: `聴き終わった印象としては` `この作品いちばんの特徴だと感じました`（1本1回まで）

## ドライオーガズムと脳イキ

- **別物。** `ドライオーガズム（脳イキ）`・同一視禁止。台本がドライなら絶頂の主語はドライオーガズム。

## 「向いた」系の置き場所（おすすめへ・2026-06-11）

**`向いた` `向いている` `向いています` `向いた一本` `に向いている`** など、読者の**向き／おすすめ判定**は **`**【こんな人におすすめ】**` ブロック（`RECOMMENDED_*`・`RECOMMENDED_*_REASON`・`recommendedFor`）だけ**に書く。

| 禁止（書かない） | 代用 |
|---|---|
| `summary`・`itemDescription`・グラフ内訳・`## 総評`三柱・`workImpressionParagraphs` の `〜方に向いた` `向いていると感じ` | おすすめのラベル／理由へ移す。結論は**余韻・収穫・関係の進み**で締める |
| `### 【結論】` でのおすすめ判定 | `聴き終わったあと〜が残る` `〜まで一本で続く` 等 |

**例外** … 公式トラック名（例: `気が向いたから`）・台詞引用（`> ` 行）・`### パートの長さ` 表のカタログ。

※ **`向きます`** は従来どおり全文禁止（`合います`・`噛み合います`）。**`向きにくい`** は合わないブロックでも禁止（§0.3）。

## 【合わない可能性がある人】（§0.3）

- **時間／尺を理由にしない** … ラベル・理由・`notRecommendedFor` すべて。**`短時間で完結させたい方` は禁止**（代表例）。
- **快感欲求ラベルを立てない** … **`すぐに快感を求めたい方`** **`快感を急いでほしい方`** 等、リスナーが「快感を先に／急に」欲する像を合わない理由にしない。理由も **`すぐに絶頂へ`** **`じれったい`** **`深化に時間をかける`** 等の早さ・欲求主語を避ける。
- 代用 … **誘導・トーン・刺激の相性**（例: `穏やかな催眠誘導だけを好む方`／単線誘導を好む／矛盾文が苦手／ドライ中心が合わない）。
- 尺の事実は `### 梱包ファイル`・`recording` へ。合わない判定の根拠にしない。
- **見本をコピーしてもこの禁止は解除されない**（本書ルール最優先）。

## 【合わない】全年齢同人（`tags: 全年齢同人`）

- **性描写の有無**を合わない理由にしない … `直接的な性的描写を期待する方` `露骨な性的描写` `肉体的な刺激を求める方` 等（**R18 前提の当たり前**）は禁止。
- 代用 … **作風・シチュ**／**刺激・音像・テンポ**の不一致。正本: `docs/全年齢シチュエーションボイス執筆ガイド.md` §5.1。
- **クイック `notRecommendedFor`** も同様（ラベルのみ・理由は `index.md`）。
