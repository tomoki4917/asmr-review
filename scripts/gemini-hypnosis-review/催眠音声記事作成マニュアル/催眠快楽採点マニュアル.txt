# 採点マニュアル（リポジトリ正本派生・HYPNOSIS_MANUAL_DIR）

対象軸: 快楽度

# レビュー執筆・採点運用ガイド（評価基準と作成手順）

この文書は、**管理人・編集担当・執筆支援（AI 含む）**がレビューを「同じ物差し」で進めるための**運用まとめ**です。細目の定義は **`docs/レビュー三軸評価定義.md` が正本**であり、ここでは**決めごとと手順**を優先して書きます。

---

## 1. 評価が対象としているもの

- **対象**：同人・商業の**催眠音声**を、**鑑賞用レビュー**として評価する。
- **明示しないこと**：臨床催眠の効果検証や治療適性は**保証しない**（三軸定義どおり）。
- **語の置き方**：「催眠」「トランス」は娯楽の口語だけにせず、学習で扱う範囲の意味に寄せて書く努力をする。

---

## 2. トランスありき（本サイトの標準）

読者向け本文に見出しを足す必要はない。**編集・`_分析データ.json`・レビュアー内部の物差し**としてだけ使う。

1. **まず `scores.trance`（トランス度）を決める。**  
   誘導・暗示・没入が薄いと判断したとき、**快楽度・満足度だけを極端に高くしない**（読者から見て「催眠レビュー」の説得力が落ちる）。
2. **快楽度**は、「催眠として提案が届いている」と読める状態を前提にした**報酬設計**として読む。
3. **満足度**は、**トランス・快楽・解除を含む体験全体**として読む（①約束回収 ②快感経路の充実 ③解除の物語 ④尺対密度）。安心余韻必須ではない。一般エロ音声と横並びにしない。
4. **例外**：作品が催眠とは別コンセプトを前面にしているときのみ、軸どうしのずれを許容してよい。そのときは **`_分析データ.json` の `notes` に理由を一文書く**。

**「深さ」を厳しめに見る（特に短尺）** … **尺が短いこと自体は減点にも加点にもしない**（「短いから深さも上がる／下がる」は使わない）。**深さ**は、往復・多段・変性意識としての作劇が**どれだけ持続するか**で見る（定義書の細目 **A**）。**本編の大半が報酬・支配の語り**に寄る構成では、**入り（乗りやすさ）**がよくても**深さだけは高くつけにくい**。**甘く見やすい落とし穴**なので、**約30分前後の作品で「深さ」だけを 7 と置くときは特に慎重**にする。θ帯を長く耕すような連続深化が読み取れず、報酬側の頭側飽和が主になる場合は、**深さ 5〜6 帯**も選択肢とする。

参照：`.cursor/rules/review-trance-first-scoring.mdc`、`docs/レビュー三軸評価定義.md` の「トランスありき」。

## 3. 三軸の意味（短く）

| 軸 | 見ること（要点） |
|----|------------------|
| **トランス度** | 暗示・誘導への没入の深さ、台本が注意を内向きにどこまで引けるか。**「催眠の体裁」だけで加点しない。** エロ報酬が主で没入が浅いと感じる場合は下がりやすい。 |
| **快楽度** | **その作品が売っている快感のコンセプト（C-0）**に対して、期待と報酬・反復設計が筋通りか。**喘ぎの多さだけで並べない。** |
| **満足度** | **体験全体の回収**（約束・快感経路・解除の物語・尺対密度）。「気に入ったか」の総合満足と同義にしない。安心余韻必須ではない。 |

**観念としての「入り」と「深さ」** … 消えていません。**正本の `docs/レビュー三軸評価定義.md`** では、トランス度を見るとき **深さ**に加え **乗るまでの手厚さ**（導入・補助・前処理）と **本編を通した型・戻り**を一体として書いています（「執筆上の三軸の扱い」）。記事本文で **`入り`／`深さ`** とラベルを付けるのは **執筆上の省略記法**であり、`docs/真催眠音声執筆ガイド.md` §1（補）項5 の **グラフ軸行** に **`トランス度 n（入り x / 深さ y）`** と **推奨**として載っています（同ファイルに **快楽度：快感設計／絶頂シーン**、**満足度：着地／余韻** の併記例あり。**快楽度**の括弧内の共通定義は、**快感設計＝絶頂へ至る「焦らしと高まり」の設計**、**絶頂シーン＝絶頂局面そのものの設計・終端回収**（旧ラベル「ピーク回収」から改称・2026-05））。実例：`src/content/レビュー/nouiki-trip-denpa-live/index.md` の `## 総合評価`。すべてのレビューがこの形式である必要はなく、短く書いた記事では一行にまとめるだけの場合もあります。

詳細・チェック表は **`docs/レビュー三軸評価定義.md`** の A〜D と C-0 の成功定義を見る。

## 4. 総合の星（`ratingValue`）

- **三軸の単純平均を機械的に必須としない。**  
  偏りがあるときは本文・`notes` で読者が納得できるように書く。
- 星を付けるときは、三軸に加えて **作品としての完成度**（構成・表記と実体の一致・制作の破綻の有無）を必ず頭に置く（定義書「総合の星を付けるときの判断材料」）。
- **本文では**、「想定読者は…」など**採点のメタ注釈**を `## 総合評価` に書かない。物差しはこのドキュメントと定義書に置く。

### 4a. 総合の星と冒頭（`summary`）口調（2026-05）

**一覧カードに載る `summary` の義務**は、**総合 `ratingValue`** で切り替える。

| 帯 | 方針 |
|----|------|
| **★9〜10** | **熱量・ねじれフック許容**。催眠は `docs/真催眠音声執筆ガイド.md` §2 既定／特例。同人は `summary` の **`--その〇〇へ、`** 等（`src/content/記事/_同人音声執筆ガイド2.md`）。 |
| **★8 以下** | **構成説明型を標準**。見本：**`src/content/レビュー/futarigake-saimin-dry-iki-support/index.md`**（誘導の並び・区間・終端が読める説明。**不可逆警告や三段脳ハックを義務にしない**）。同人も同趣旨。 |

## 5. ★10 とベンチマーク（インフレ防止）

- **10** は「欠点がほとんど言いにくい」と言えるときだけ。**迷ったら ★9 止め**や本文での減点理由を優先してよい。
- **総合★10 が複数あってよい**が、**売っている約束（コンセプト）が異なるレーン同士**での話。**無関係なジャンルを★だけで横並びにしない。**
- **サイト内ベンチマークの参照例（あくまで例）**  
  - 王道・長尺深化：`unknown-hypno-daijobu-koe-ni-yudanete`  
  - ふたりがけ・情緒・幸福系オーガズム：`futarigake-saimin-love-happy-orgasm`（別コンセプトの厚み：`futarigake-saimin-melty-orgasm`）
- **低評価側の比較アンカー（完成度比較の下限）**  
  - 催眠としての深さが薄く、着地の回収が弱いときの基準：`saimin-shinri-test-dame-iwakareru`（総合★3）  
  - 新規採点時は、**「この作品は★3アンカーよりどこが明確に上か／★10アンカーよりどこが明確に届かないか」**を最低1つずつ `notes` に書く（完成度比較を固定するため）。

詳細は `docs/レビュー三軸評価定義.md` の「10点満点の見取り」。

# レビュー評価体系（定義）

同人音声・商業催眠音声を対象に、**鑑賞用レビュー**として採点する際の共通語彙です。  
**臨床催眠の効果検証や治療適性を保証するものではありません。** ただし「トランス」「催眠」という語を、**娯楽表現として緩く使うのではなく**、学習で扱う範囲の意味にできるだけ揃えて記述します。

---

## 三軸の意味（鑑賞用）

レビュー対象は **催眠音声** です。**臨床催眠の効果検証や治療適性を保証するものではありません。**

- **トランス度** … 暗示・誘導への**没入の深さ**、台本が聴き手の注意をどこまで内向きに引いていくか。**物語として「催眠の型」が揃っているだけ**で点数を大きく上げない。**性的報酬が主で、深い没入としては浅い**と感じられる作品は下がりやすい。
- **快楽度** … **期待と報酬**、条件づけに近い反復・トリガー、感覚描写の強さ。作品が**どの経路の快感を主に売っているか**（コンセプト）を先に捉え、そこに対して筋が通っているかを見る。
- **満足度** … **トランス・快楽・解除を含む体験全体**の回収（①約束回収 ②快感経路の充実 ③解除の物語 ④尺対密度）。安心余韻必須ではない。長尺作品を「短い方がよい」という**別物の物差しで一蹴しない**。**満足度**は、**作品全体が気に入ったか**という意味の**総合満足**と**同義**にしない。長尺の**聴取負担**・**歌唱・MCの好き嫌い**は、**戻しの完成度**と**混同せず**、`## どんな人におすすめか`／`合わない人`・必要なら**本文**で分岐させる（下記「執筆上の三軸の扱い」）。

### トランスありき（本サイトの標準採点・2026-04）

読者向け本文にこの見出しや説明文を足す必要はない。**編集・`_分析データ.json`・レビュアー内部の物差し**としてだけ使う。

1. **まずトランス度を決め、快楽度・満足度はそれと整合する範囲で付ける。** 催眠として誘導・暗示が薄い のに快楽・満足だけを高く付けると、レビューの信用を損ねやすい。
2. **快楽度**は、喘ぎや実演の強さだけでなく **「催眠として提案が届く状態」を前提にした報酬設計**として読む。**満足度**は **トランス〜快楽〜解除までを含む体験全体**として読む（一般エロ音声と横並びにしない）。
3. **例外** … 作品自体が催眠とは別経路（別コンセプト）を前面にしており、`_分析データ.json` の `notes` で明示できるときのみ、軸どうしのずれを許容してよい。

4. **主要誘導の `身体の変化`（全作品）** … `_分析データ.json` の三軸・総合評価と**整合**させる。トランスが低いのに深化を厚く書く、快楽が低いのに催眠的快楽だけを盛る、満足が低いのに完全覚醒だけで締める、といった矛盾は禁止。詳細は `docs/催眠音声執筆ガイド.md` §4.5。

### 評価の前提（完成度主軸）

三軸・総合の星の**主な物差し**は、**ジャンル・属性の好き嫌い**ではなく、次を一体として見ることである。

1. **作品が売っている約束**（コンセプト **C-0**）と**着地**（**D**）への応え方  
2. **構成・段取り・台本・音響・演技**など、**制作としての完成度**（下記「総合の星を付けるときの判断材料」）  
3. **尺に見合う密度**（空転がないか、締めが手抜きでないか）

**フリートーク等（採点対象外）** … **声優フリートーク・収録メイキング寄りのボーナストラック**は、**本編の催眠体験の完成度**には含めない。三軸・総合の判断、および「尺に見合う密度」の見方は、**催眠の導入〜本編〜解除／覚醒まで**を基準にし、フリートーク等は**加点にも減点にも使わない**。パート一覧や本文で触れてよいが、**評価の根拠に据えない**。

**好みで上げ下げしない** … マゾ向け・非エロ・長尺誘導など、**好みが分かれる型**だからといって点数を自動的に上げ下げしない。**その型のなかで約束がどれだけ果たされているか**で見る。

**「主観差」で星を逃がさない** … 三軸や総合の**上下の主な理由**に、**聴き手の好みの当たり外れ**や**個人差**を**据えない**（点数の免罪符・減点の口実の両方に使わない）。聴取条件や地雷は `## どんな人におすすめか`／`合わない人`・本文で事実として示せば足りる。

**制作上の欠点は厳しめ** … 明らかな**台本の誤読**・**口滑り**・不自然な**同一テイク**、**編集の破綻**、**聴取を妨げる持続的ノイズ**などは、**嗜好**ではなく**制作品質**の問題として扱い、該当する軸（主に満足度。状況により快楽度・総合）を下げうる。軽微でなければ本文または `_分析データ.json` の `notes` に**箇所**を示す。問題が**見当たらなければ**、ない前提で**捏造した指摘**は書かない。

**快楽度と実演・R18** … 喘ぎの多さ、生殖器の実演、ウェット描写の有無だけで全作品を横並びにしない。**その作品の C-0 が主に売っている快感の経路**（音・幸福感・ドライ・カウント等）に対して、**期待と報酬の設計が緻密か**で付ける。**音や心象だけを中心に据えた作品でも、設計が極まっていれば快楽度10はあり得る**（「エロがないから10にできない」という物差しにしない）。**このときも、催眠音声としてトランスが十分であることを前提とする**（上記「トランスありき」）。

**酷評は残す** … 約束の回収が悪い・着地が雑・誘導が薄いなど**完成度の欠け**がある作品は、**ニッチに刺さるから**といって星や三軸を持ち上げない。**駄作に甘い点数**を付けない。

**`## どんな人におすすめか`／合わない側ラベル の位置づけ** … **誰に届くか・地雷の案内**であり、点数の**免罪符**にも**インフレの口実**にもしない。星・三軸の説明と、**合わない側**（`**合わない可能性がある方**` または `**合わない人**`）に書いた**本質的な欠点**が食い違う書き方は避ける（体裁の正本は `docs/真催眠音声執筆ガイド.md` §2・`.cursor/rules/review-prose-voice.mdc`）。

**10点満点の見取り** … 三軸・総合ともに**欠点がほとんど言いにくい**レベルで揃っているときに限り、**10** を付けてよい。**総合★10が複数あってよいが、売っている約束（コンセプト）が異なる**。他作品を不当に引き下げるためではなく、**同じタイプの約束を売る棚のなかで完成度が届くか**を見る。**無関係なジャンル同士を★だけで横並びにしない**。ベンチマークの参照例（レーン別）… **王道・長尺深化・往復の厚み**：`unknown-hypno-daijobu-koe-ni-yudanete`（アンノウンヒプノ ～大丈夫、私の声に委ねて～）。**ふたりがけ・情緒・幸福系オーガズムとして約束〜着地まで筋が通る完成**：`futarigake-saimin-love-happy-orgasm`（ラブハピ編）。同じくふたりがけシリーズで別コンセプトの厚み参照なら `futarigake-saimin-melty-orgasm`。**★10を増やすほどインフレが進むので**、迷ったら★9止めや本文での減点理由を優先する。

**本文では** … 「想定読者は、上の『どんな人におすすめか』に…」のような**評価前提のメタ注釈**を `## 総合評価` に書かない（物差しはこの節とルールに従い、本文では作品の根拠だけを書く）。**曖昧な便利語だけで段落を終えない**（例：「挟みやすい」だけでは何を挟むか不明）。**「主菜」比喩は読者向け本文では使わない**（軸・中心・土台等へ）。細目は `.cursor/rules/review-prose-voice.mdc` と `docs/真催眠音声執筆ガイド.md` §3e 項8・項9。

**「催眠」と銘打っているだけでトランス度を上げない。** 中身として誘導・暗示が薄い作品は減点する。  
**ジャンル演出の体裁**と、実際に**どれだけ引き込まれたか**を混同しない。

各軸は **10.0 満点**。数値は `_分析データ.json` に記載し、`review_triangle.png` は **トランス度・快楽度・満足度の 3 数値のみ**から生成します（細目は本文・`notes` で補足）。スキーマは `docs/schemas/review-analysis.v1.schema.json`。

### 執筆上の三軸の扱い（記事本文・採点の一貫）

- **トランス度** … 催眠音声では**誘導・没入**を**中核**の一つにする。**深さ**に加え、**乗るまでの手厚さ**（導入・補助・前処理）と、**本編を通して型が一貫し、戻るか**を**一体**として見る（細目 **A・B**）。表示だけで上げない（上記のとおり）。
- **快楽度** … 軸として**分ける**（表示は独立）が、**没入の上に乗る報酬**のとらえ方で、同じ作の**聴感**で不自然に**没入と快楽**を切り離さない。快楽は**主に**、作品が売っている**約束する快感**（**C-0** を先に言語化し、**C-1** で実装を見る）に対する**期待と刺激設計**。
- **満足度** … **体験全体**の回収（約束・快感経路・解除の物語・尺対密度）。**総合**（`ratingValue`）や「**気に入ったか**」の**代理**にしない。長尺の**聴取負担**、歌唱・MCの好き嫌いは、**戻しの不備**と**混同せず**、`## どんな人におすすめか`（合わない側を含む）・**本文**で分岐する。
- **「相性」** … 聴き手の**好みの当たり外れ**を、三軸・総合の**主な減点理由**に**据えない**（上の「**主観差で星を逃がさない**」と同趣旨）。おすすめ欄で**分岐**すれば足りる。
- **高得点同士の整合** … **トランス**と**快楽**が**ともに高い**のに**満足度**だけ**大きく**低い、という採点は、**戻し・帳尻**に**事実上の欠陥**がある**とき**に**限**り、**理由を本文**（または `notes`）**で説明**できるようにする。逆に、トランスの示し方が一辺的でも、**戻る手続き**で**満足**が**立ち上がる**ことはありうる。**トランスが低いのに快楽・満足だけ高い**という付け方は、上記「トランスありき」により**標準では取らない**（別経路を前面にできるときは `notes` で明示）。
- **各記事の「グラフ評価内訳」**（`index.md`）… **一般読者向け**。**C-0**・**D-0** 等の**略号**は**出さない**（分析用ラベルは `_分析データ.json` の `notes` 等。トーン例は `src/content/レビュー/unreal-hypno/index.md` 同節。細則は `.cursor/rules/review-graph-no-boilerplate.mdc`）。

## 出来の判別（口語では「駄作／良作」）

表示上は三本の軸があるが、**本サイトの標準採点では「トランスありき」**（冒頭の節）に従う。**その作品が売っている約束（C-0）に対して各軸が筋通りか**で見る。**催眠とは別経路が前面の作品**など例外は `_分析データ.json` の `notes` で明示する。

### 軸ごとの「低めになりやすい」条件

| 軸 | 下がりやすい典型 |
|----|------------------|
| **トランス度** | **多段の深い誘導が弱い**、会話や軽いリラックスに留まる、**エロ報酬が主で没入の深度が浅い**と感じられる。カリギュラ等で「ダメ」が**古典的な分析停止とは別物**（欲求の活性化が主）なら、トランスとは別評価。 |
| **快楽度** | C-0 と中身が矛盾、**起伏が単調**、アンカリングが雑、コンセプトとの**ズレ**。 |
| **満足度** | 約束が未回収、快感経路が単調で空転、解除の物語が雑、**未完了感**だけ残る。安心余韻がないこと自体は減点しない。**中尺・長尺なのに尺に見合う密度・締めがなく**空転する。 |

### 「良作」に寄りやすいパターン（目安）

- **トランス** … 誘導・深化に**尺と手順**があり、**往復・多段**などで深さの作劇が芯になっている。A の複数細目が**同時に**高いほど、トランス度も上がりやすい。
- **快楽** … C-0 が明確で、C-1 の**期待と報酬・アンカリング**が一貫している。長尺でも**密度が落ちない**設計。
- **満足** … D-0 で約束を回収し、**解除・覚醒・日常への橋**が読み取れる。必要なら**副交感優位・心拍**などの**任意の生体ログ**（個人差大）を本文で補助してよい。

### 「駄作」に近いと言いやすいパターン（目安）

- **掛け声だけの催眠** … 誘導が薄く R18 だけが長い → **トランスが低ければ快楽・満足も引きずりやすい**（標準採点）。過去レビューで「トランス低・快楽だけ高い」になっているものは、改稿時に整合を確認する。
- **約束と中身の不一致** … タイトル・販売文とパートが噛み合わない、解除がない／曖昧で **D が壊れる**。
- **細目のどれも中位以下** … 三軸とも伸びない。総合（`ratingValue`）も下がりやすい。

※ **駄作／良作**は最終的にレビュアーの総合判断。数値は**読者が納得できる根拠**を `_分析データ.json` と本文に残すことが先である。

## 評価の階層（洗い出し）

### A. トランス形成（変性意識へ至る手前〜トランス）

**Critical Factor（批判的因子／現実検討を司る側面）をどれだけ迂回・飽和させ、注意を内部へ預けられるか**を中心に見ます。

| 細目 | 見ること |
|------|----------|
| **脳波の遷移（推定）** | 実測脳波は原則なし。**呼吸・カウント・単調反復・無音の切れ目**など、α〜θ帯への移行を**音響と台本がどれだけ誘導しうるか**を推定する。深いθ帯を狙う多段階設計か、リラックス止まりか。 |
| **コンフュージョン（混乱技法）** | 意味の揺らぎ・逆説・認知負荷で分析を飽和させ、CF を一時的にバイパスしやすくする技法。**意図的な混乱の密度**（安易な冗長さとの区別）。**往復・浅覚醒の挟み**は別技法だが、深さの作劇としてはここと関連して記述してよい。 |
| **ASMR・感覚誘導** | 定位・囁き・耳介刺激など、**体性感覚野への共感覚的入り口**として機能しているか。単なるBGMか、トリガーとして繰り返し使われるか。 |
| **ラポール** | 声の距離感・共感・「一緒に進む」感。**信頼関係の土台**として台本と演技が噛み合っているか。 |
| **CF バイパス（総合）** | 上記の結果として、**「いまはルールに身を任せてよい」状態**に聴き手を載せられるか。倫理・安全の枠（注意事項）と矛盾しない範囲で評価する。**カリギュラで欲求を立てる**場合は、古典的な「分析停止」とは別物としてメモする。 |

→ これらの総合を、表示上の **「トランス度」** に反映する。**厳しめに見ると**、誘導が軽い・コンフュージョンが薄い・**深い θ 帯を狙う多段構造が弱い**場合は下がりやすい。**エロ報酬が主目的で、変性意識としての深度が浅い**と推定される作品も下がりやすい（掛け声だけの「催眠」は特に）。

---

### B. 催眠状態としての「完成」度

トランスに近い受容状態のうえで、**暗示がどれだけ筋の通った「催眠体験」として立ち上がるか**。

| 細目 | 見ること |
|------|----------|
| **感応性への配慮** | 強い指示の前に**許容・選択・段階**があるか。一方的な煽りだけでないか（※成人向けの「拒否できない」演出は、**フィクションとしての危険度**と区別して記述）。 |
| **暗示内容** | 主題（カリギュラ、カウント、身体感覚など）が**一貫して積み上がるか**、**反復と矛盾**で薄まらないか。安全に戻す出口・解除の明瞭さもここに含める。 |

→ **トランス度**（深さ・誘導技術）と重なる部分と、**満足度**（完結性）にまたがる。

---

### C. 快楽度（報酬系・刺激設計）

作品ごとに **「どんなイき方・どんな快感の質を主役にしているか」**（販売文・タイトル・構成から読み取れる**コンセプト**）があります。  
**すべての作品を「喘ぎの多さ＝快楽」で測らない**こと。コンセプトに対して**筋が通っているか・密度があるか**を見ます。

#### C-0. 狙う快楽のコンセプト（先に言語化する）

レビューでは、可能な範囲で次のような**軸**のどれを主に狙っているか（複合可）を一言で固定してから細目を見る。  
ラベルを付けたあとは、**下記「各タイプの成功定義」**に照らして「約束がどこまで果たされているか」を文章化し、**C-1** の刺激設計と突き合わせる。

| タイプ（例） | 一行定義（速査） |
|--------------|------------------|
| **脳イキ** | 生殖器描写より**頭の中・思考停止・幻肢・イメージの飽和**で快感を立てる作り。 |
| **幸せイキ／情緒イキ** | **安心・恋愛・肯定**と快感が同時に立ち上がる。「気持ちいい＝幸せ」の一体感。 |
| **堕落イキ／背徳イキ** | **道徳・自制の喪失**や「ダメなのに進む」ことが報酬になる設計。 |
| **ドライオーガズム** | **射精を伴わない／別ルートの絶頂**を台本・指示・間で主役にする（前立腺・PC筋・逆行などの語りと整合）。 |
| **トリガーイキ** | **特定の語・音・リズム・パターン**に快感が結びつく**条件反射・フック**が主役（アンカリングの極端な形）。 |
| **その他（併記する）** | カリギュラ、カウント絶頂、寸止め地獄、プロスタート、複数絶頂、など。**作品が売っている約束**に合わせてラベルを足す。 |

※医学的定義や再現性の保証ではなく、**台本・音響が聴き手にどの経路の快感を主に売っているか**の読み取りです。併せて **C-1** の報酬・条件づけの強さを、**快楽度**の生物学的・心理生理的な手がかりとして使う。

##### C-0 各タイプの成功定義（鑑賞用・詳細）

「成功」とは**そのコンセプトを主役に据えたとき、快楽度が高く評価されうる状態**を指す。すべて満たす必要はなく、**どの条件が効いていてどこが欠けているか**を `_分析データ.json` の `notes` や本文に残すことが先である。

**脳イキ**

- **成功の目安**
  - **快感軸の一貫性** … クライマックス列（複数あってよい）で、快感の説明・指示・間が**頭側・心象・思考の変化**に軸足を置いている。生殖器・体液が出ても**従**であり、そちらに物語の山の説得力が奪われていない。
  - **飽和の設計** … イメージ誘導・カウント・無音・囁き・反復の**層**があり、単一フレーズのコピペだけで「頭がいっぱい」にならない。**浅い煽りのループ**で代用していない。
  - **対象の言語化** … 思考停止・幻肢・身体像の書き換えなど、**何が飽和しているのか**が台本内で追える（聴き手が勝手に補完するだけに任せきらない）。
  - **トランスとの分担** … 深さの手順（A）と頭側の報酬（C）が**同じレーン**で噛み合い、「深い催眠」と「脳の快感」が別パートでバラバラになっていない。
- **弱い／失敗寄りの兆候**
  - 喘ぎ・淫語・効果音の刺激が主で、**頭側の山が説明不能**になっている（タイトルだけ脳イキ）。
  - **下品さや禁句の羅列**で緊張だけ上げ、心象の積み上げがない。
  - 尺の大半が導入で、**頭側のクライマックスが短い／1回の決め台詞で済ませている**。

**幸せイキ／情緒イキ**

- **成功の目安**
  - **情緒と性感の同位相** … 肯定・恋愛・安心の台詞（ラポール）と、快感の山が**時間軸で重なり**、「気持ちいい」と「幸せ／愛されている」が**同じ瞬間に立つ**場面が設計されている。
  - **報酬の質の一貫** … 販売文が掲げる情緒（例：甘やかし・救済・ご褒美）と、**実際の合図・反復・クライマックスの語彙**が矛盾していない。
  - **空転のなさ** … 情緒パートが長いだけで性感が遅れ、または逆に性感だけが先行して**情緒が後付け**になっていない。
- **弱い／失敗寄りの兆候**
  - セリフは幸福系だが、**音と喘ぎは汎用エロ**で、情緒のレーンが切れている。
  - **肯定の言葉がテンプレ連打**で、物語・関係性の積み上げがなく「言葉だけ幸せ」になっている。

**堕落イキ／背徳イキ**

- **成功の目安**
  - **段階の説得力** … 道徳語彙・自制・関係性のルールが先に置かれ、**破る理由**（誘惑・強制・自己像の変化）が段階を踏んで積み上がる。「ダメ」が**意味を持ったあと**に崩れる。
  - **報酬の所在** … 「ダメなのに進む」「恥なのに止まらない」ことが**快感と同一**として描写され、単なる暴力や強制の羅列でない。
  - **ジャンルとの整合** … 敗北・洗脳・背徳など、**売っている背徳の型**と着地（D）が噛み合う（無垢ハッピーエンドだけで矛盾しない／矛盾するなら意図が読める）。
- **弱い／失敗寄りの兆候**
  - **禁止語・恥辱語の連打**だけで、状況・動機・自己像の変化が追えない。
  - 背徳が**笑いやテンプレ**で薄まり、緊張が続かない（意図的なコメディ作品を除き、コンセプトがズレる）。

**ドライオーガズム**

- **成功の目安**
  - **ルートの一貫** … 前立腺・PC 筋・呼吸・禁止・リズムなど、**選んだルートの語り**が導入から解除まで矛盾なく続く。クライマックスが**そのルートで回収**されている。
  - **身体の説明と間** … 射精と区別される感覚が、**指示と沈黙の長さ**で支えられている（早口だけで済ませていない）。
  - **ウェットへの逃げ** … ドライを売りにしつつ、**実質は射精オチや体液描写が主**になっていない。
- **弱い／失敗寄りの兆候**
  - 用語だけ借りて、**リズム・禁止・身体部位の誘導が汎用**で、ルート固有の山がない。
  - **ドライと宣言しつつクライマックスは従来の射精誘導**に寄せており、C-0 と実装が食い違う。

**トリガーイキ**

- **成功の目安**
  - **条件づけの三部構成** … （1）フックの提示と意味づけ（2）快感・深さとの結びつけの反復（3）変奏・強化・クライマックスでの発火、が**聴き取れる設計**になっている。
  - **フックの純度** … 特定の語・音・リズムが**意図的に前景化**され、他の刺激に埋もれない（C-1 のアンカリングと重なるが、ここでは「主役として立っているか」を見る）。
  - **過学習の回避** … 同じフックの機械反復だけでなく、**深さや文脈の変化**とセットになっている。
- **弱い／失敗寄りの兆候**
  - フックが**たまたま繰り返されている**だけで、導入・意味づけがなく偶然の反復に見える。
  - フックが多すぎて**どれが主役か分からない**（純度の低下）。

**その他（カリギュラ・カウント絶頂・寸止め・プロスタート・複数絶頂など）**

- **成功の目安**
  - **ラベルと中身の対応** … 販売文・タイトルで掲げた**固有の約束**（例：カウント絶頂なら数え方と山の対応、寸止めなら禁止と解放の設計、複数絶頂なら各山の差分）が、**パート配分と台本で追える**。
  - **型の完成度** … そのジャンルで聴き手が期待する**起伏の型**（焦らしの段数、敗北の段階、カリギュラの「ダメ」の効き方など）が、**空振りせず**回収されている。
- **弱い／失敗寄りの兆候**
  - **タイトル・キャッチコピーだけ**が先行し、本編は別の快感設計になっている。
  - 同じ山の**コピペ反復**で尺を埋め、各ピークの意味差がない（長尺で特に減点されやすい）。

#### C-1. 共通の刺激設計（どのコンセプトにも効く）

| 細目 | 見ること |
|------|----------|
| **コンセプト整合** | 上の C-0 と**実際のパート配分・台詞・SE**が矛盾していないか。掛け声だけで中身が別物になっていないか。 |
| **期待と報酬の落差** | 焦らし・禁止・カウントなど、**ドーパミン的な起伏**。コンセプトに合った「盛り上がり方」か。 |
| **アンカリング** | 音・語・リズムが**快感と結びつく反復**として機能しているか。トリガー作品では**フックの純度**（雑多な刺激で薄まっていないか）。 |
| **感覚トリガーの強度** | 定位、喘ぎ、SE、台詞密度。**ただし**脳イキ寄りでは喘ぎ少なくてもよい＝**中枢側の刺激の強さ**で評価する。 |

#### C-2. コンセプト別に見る補助チェック（該当するものだけ）

**上記「C-0 各タイプの成功定義」**を主とし、ここではレビュー時の**短い突き合わせメモ**として使う。

| 細目 | 見ること |
|------|----------|
| **脳イキ寄り** | 頭側の**快感軸の一貫性**と**飽和の層**（C-0）。イメージ誘導・カウント・無音・囁きが**頭側の飽和**を作っているか。下品さだけで済ませていないか。 |
| **幸せ／情緒寄り** | **情緒と性感の同位相**（C-0）。ラポール・肯定・余韻の台本が**快感と同位相**か。愛着とエロのどちらかが空転していないか。 |
| **堕落／背徳寄り** | **段階の説得力**と**報酬の所在**（C-0）。禁止・恥・自己像の書き換えが**段階と説得力**を持って積み上がっているか。単語の連打で終わっていないか。 |
| **ドライオーガズム寄り** | **ルートの一貫**と**ウェットへの逃げの有無**（C-0）。身体の説明・リズム・禁止の仕方が**そのルートの約束**と噛み合っているか。雑な誘導になっていないか。 |
| **トリガー寄り** | **条件づけの三部構成**と**フックの純度**（C-0）。トリガーの**導入・反復・変奏**が設計として見えるか。たまたまの繰り返しと区別できるか。 |

→ 表示上の **「快楽度」** に直結。**R18 商業作は点数が上がりやすい**が、**単調さ・擦り減り・コンセプトとのズレ**は減点。  
**別ジャンルを同じ物差しだけで並べない**（脳イキ作品と喘ぎ主役作品を「音の激しさ」だけで比較しない）。

---

### D. 満足度（情緒・自律神経・「終わり」）

**C で立てたコンセプト**に対して、「終わり方」が**約束を果たしているか**も見ます。  
例：堕落イキ主役なのに**無垢なハッピーエンドだけ**で矛盾する、脳イキ狙いなのに**頭の方の着地がなく**身体だけ解除、などは満足度を損ないやすい。

**尺（再生時間）との見合い** … 短尺と長尺で「満足」の形は違う。**長いから満足度を機械的に下げない。** 見るのは、**その尺に対して**導入〜本編〜解除まで、**投じた時間に見合う密度・変化・着地があるか**である（**フリートーク等は尺に含めない**。上記「評価の前提」の「フリートーク等」と同じ扱い）。長尺だからこそ積める深化や余韻が揃い、締めまで含めて回収できていれば高く評価してよい。逆に、尺のわりに**中盤が薄い・同じパターンの反復だけ**で、**時間投資に見合う体験になっていない**ときは下がりやすい。

**尺の呼び方（レビュー室・本文用の目安）** … レビュー本文で作品の尺を形容するときの共通語彙です。数値の厳密な区分ではなく、**読者が「長い／普通」と誤解しない**ための指針です。

- **～約50分** … 同人催眠音声では**よくあるボリューム**です。**「長尺」とは書かない**。「標準的な尺」「およそ1本作業として聴ける尺」などと表現します。
- **50分～100分** … **中尺**です。誘導や掛け合いが厚いぶん、**尺に見合う密度**や手順の話をするときの帯として使います。
- **100分超** … このサイトのレビューでは**長尺**と呼ぶのが自然です（満足度の「尺との見合い」で「長尺」と書く場合は主にここを指す）。

#### D-0. コンセプトに対する着地（先に C-0 と対応させる）

| 細目 | 見ること |
|------|----------|
| **約束の回収** | タイトル・販売文・導入で提示した**快感の質**が、クライマックス〜後味で**ちゃんと回収**されているか。 |
| **ジャンルとしての「後味」の適切さ** | 幸せイキなら安心、堕落イキなら**背徳の余韻や代償の示唆**など、**そのジャンルで聴き手が期待する情緒の形**に寄せられているか（フィクションとして）。 |
| **ツァイガルニク・未完了感** | 意図的な続編フックを除き、**中途半端な切り**で欲求だけ残していないか。 |

#### D-1. 身体・催眠としての「戻り」

| 細目 | 見ること |
|------|----------|
| **解除・着地** | 覚醒・余韻・現実への橋。短すぎないか、置き去りにしていないか。 |
| **身体感覚の締め** | ドライオーガズム・トリガー系では、**そのルートに合った**「戻し」「余韻」の台本があるか。 |

#### D-2. 情緒・興奮後の収束

| 細目 | 見ること |
|------|----------|
| **感情の解消** | 興奮だけ残して**モヤ**が残らないか。 |
| **興奮後の収束** | 「気持ちよかったあとの安心」や、ジャンルに応じた**ホラー／背徳の処理**など、**聴き終わったあとに置いていかない**声・文があるか。 |

→ 表示上の **「満足度」** に反映。**B**（暗示の完結・安全・解除の明瞭さ）と**重なる場合は、どちらにも書いてよい**（数値は一つに統合）。

## 3 軸への集約（運用ルール）

厳密な加重公式は置かず、レビュアーが **上記細目を踏まえた総合判断**で次を決める。

| 表示 | 主に参照する層 |
|------|----------------|
| **トランス度** | **A 中心** ＋ B の「暗示が立ち上がる前段」 |
| **快楽度** | **C**（**C-0 でコンセプトを先に言語化**し、C-1・該当する C-2 で見る） |
| **満足度** | **B** の完結・安全 ＋ **D**（**D-0 で C-0 と着地を対応**させる） |

上表は**細目の帰属**の目安である。**標準では冒頭「トランスありき」どおり、まずトランスを決めてから快楽・満足を整える。** 採点の**前後一貫**（戻しと好みの切り分け、高得点同士の整合、各記事のグラフ欄で略号を出さない等）は、**冒頭「執筆上の三軸の扱い」**と**矛盾**させない。

**表記だけ**でトランス度を上げない。**トランス形成・暗示の細目（A〜B）に照らして**誘導・暗示の密度が伴うかで付ける。

**快楽度・満足度**についても、**単一の物差し（例：喘ぎの多さ、解除の長さだけ）で全作品を並べ替えない。** まず作品が主に売っている**約束（コンセプト）**を揃え、**その約束に対する刺激設計と着地**を見て採点する。**満足度**ではとくに、**短尺向けの「すぐ結果が出ること」だけを正義にしない**（上記「尺との見合い」）。

**総合の星（`ratingValue`）** … 三軸の**単純平均を機械的に必須としない**。偏りが大きい作品は本文で説明し、**読者が納得する置き方**を優先する。**完成度が低い作品は、ジャンルがニッチでも低く付けてよい**（「想定ファンがいるから」とインフレさせない）。**トランス**と**快楽**が**高い**のに**満足度**だけ**大きく**低い、という**偏り**のつけ方は、戻し・帳尻の**事実上の不備**を、本文（または `notes`）に根拠を示せるときに限る（上記「執筆上の三軸の扱い」の「高得点同士の整合」に同旨）。

### 総合の星を付けるときの判断材料（作品の完成度）

**レーダー三軸や本文に「完成度」という第4スコアを追加する必要はない。** グラフは従来どおり **3 数値のみ**。

ただし **`ratingValue`／本文の `★n／10` は三軸の機械平均ではない**（上記どおり）ので、星を付ける**判断の段階**では、次のような **作品としての完成度** を**必ず突き合わせる**（三軸の説明と星がかみ合わないときは、完成度の見落としがないか疑う）。

| 見ること（例） | コメント |
|----------------|----------|
| **構成・段取り** | パート配分に破綻がないか、テンポの穴が目立たないか。尺に対して同じパターンだけが続く**空転**は満足度側にも出るが、**段取りとしての緻密さ**はここで見る。 |
| **コンセプトと実装の一致** | 販売表記（収録内容・トラック構成・尺）と実聴の印象が大きく食い違わないか。快楽度の **C-1** と重なるが、**「約束の快感」より制作・パッケージとしての筋の良さ**に寄せてよい。 |
| **制作面の破綻** | 台本・演技・SE・音量のバランスが作品の温度を損ねていないか。**明らかな編集ミス・収録事故・ノイズ**が続く場合は星を下げる材料にする（個人の機材差は断定しすぎない）。 |
| **満足度との役割分担** | **満足度**は主に **情緒・解除・約束の回収・後味**。**ここでいう完成度**は主に **制作・構成の上手さと表記の整合**。両方が高い作品は星も上がりやすいが、**片方だけ高い**こともありうる。 |

**本文では** … 完成度の評価を**三軸の箇条書きや「以上から総合」の前後**に無理に数値化する必要はない。**作品像・パート解説・感想**のどこかで、構成や制作の良し悪しが伝わっていればよい。`_分析データ.json` の `notes` に **「星の判断メモ（完成度含む）」** を残すのは任意。

## `_分析データ.json` の書き方（推奨）

レビューごとに、少なくとも次をコメントで残すと、**駄作／良作の根拠が後から追いやすい**。

1. **評価方針** … 本ドキュメントに基づく旨（臨床非保証）。**トランスありきで三軸を揃えたこと**がわかる一言があるとよい。`notes` の先頭付近に書くとよい。
2. **A** … `脳波遷移` `コンフュージョン` `ASMR` `ラポール` `CFバイパス` それぞれ **10 段階の目安**と一言理由（`notes`）。
3. **B** … `感応性` `暗示内容の一貫` など（`notes`）。
4. **C-0** と **C-1** の要点（快楽度の総合コメント、`notes`）。
5. **D** … 満足度の要点（D-0〜D-2 を統合してよい、`notes`）。
6. **グラフ用** … `scores.trance` / `scores.pleasure` / `scores.satisfaction`（0〜10、`review_triangle.png` 用）。
7. **絶頂目安（任意）** … 本文の `## 総合評価` に **ドライ／ウェット（またはウェット無し）** を書くとき、同じ内容を **`orgasmSummary`** にも残すと、改稿時の突き合わせがしやすい。**括弧内はイき方の種類（系統名）に限定**し、**被包摂・育児退行**など**ジャンル属性**は絶頂行に重ねない（`tags`・作品概要・本文に任せる）。**山の違い**（例：台本の**授乳帯／キス帯**）と**本数**の**突合**は `notes` に回してよい。下表「イき方の系統」の **情緒イキ**、**脳イキ**、**セルフ射精** 等に寄せ、**作品固有造語**（例：授乳イキ）を**正ラベル**にしない方針とする（執筆ガイド **2026-04-27** 追記、`.cursor/rules/review-prose-voice.mdc`）。

旧ラベル（例：`T_ie` / `D_si` / `H_er`）だけではなく、**上記 A〜D の語彙に寄せて更新**することを推奨する。

## データファイルとの対応

- レビューごとの **3 数値** と任意の **細目メモ** は `src/content/レビュー/<slug>/_分析データ.json` に書く（`docs/schemas/review-analysis.v1.schema.json`）。
- グラフ画像 `review_triangle.png` は `scripts/generate_review_triangle.py` で生成する。

```bash
py -3 scripts/generate_review_triangle.py <slug>
npm run sync:content-assets
```
