# シチュエーションボイス五軸採点ルーブリック（Gemini 評価脳用・リポジトリ正本）

## 手順（軸ごと・必須順）

1. **シナリオ軸のみ** … **シチュレーン（型）を1つ決める**（下表5種）
2. **当該軸の評価要因**を Whisper 根拠付きで **0.0〜10.0（0.1刻み）** とする
3. **レーン別／軸別重み**で合成 → **弱い要因の引きずり**を適用 → 最終点
4. **比較アンカー**（dakimakura / michikusa 等）との位置関係を1文

**禁止:** 催眠三軸・トランス深度・脳イキ／ドライ型語を主理由にしない。フリートーク・NG集・メイキングは採点に含めない。

**読者向け記事** … 要因名の見出し・要因ごとの点数は **eval にのみ**。`index.md` グラフは軸1点＋要約文。

---

## シチュレーン（作品の約束・シナリオ軸で1つ）

| ID | 名称 | いつ使うか |
|----|------|------------|
| `pure_progression` | 純愛・関係進展型 | 告白・恋人・同居など**関係の温度上昇**が芯 |
| `taboo_corruption` | 背徳・NTR型 | 寝取り・浮気・秘密関係・罪悪と快感が芯 |
| `gimmick_driven` | ギミック驱动型 | 抱き枕・メイド・設定の**仕掛けが進行のエンジン** |
| `intimate_asmr` | 密着ASMR型 | 耳語・添い寝・触覚密着が芯。物語は薄めも可 |
| `healing_allages` | 癒し・安眠型 | 就寝・情緒ケア・全年齢の安心が芯 |

副レーンは付けない（迷ったら **主レーン1つのみ**）。レーンは **シナリオ軸 eval で決定**し、以降の軸 eval でも同じレーンを前提に読む。

## 1. シナリオ軸 — 4要因

| 短ラベル | 要因 | 見ること |
|----------|------|----------|
| **心理** | 心理・空間の生々しさ | 場の空気・心情が台詞と間で立つか |
| **一貫性** | 世界観の内的一貫性 | 呼称・立場・時系列の矛盾がないか |
| **ギミック** | ギミックの機能性 | 売りの仕掛けが各パートの進行に効くか |
| **フック** | フックの独自性 | 冒頭・タイトルの約束が他作と被らず残るか |

### レーン別重み（合成式）

```
合成 = round(心理×w1 + 一貫性×w2 + ギミック×w3 + フック×w4, 1)
```

| レーン | 心理 | 一貫性 | ギミック | フック |
|--------|------|--------|----------|--------|
| pure_progression | **0.30** | 0.25 | 0.20 | 0.25 |
| taboo_corruption | **0.30** | 0.25 | 0.25 | 0.20 |
| gimmick_driven | 0.20 | 0.20 | **0.35** | 0.25 |
| intimate_asmr | 0.25 | 0.15 | **0.30** | **0.30** |
| healing_allages | **0.35** | 0.25 | 0.15 | 0.25 |

**4要因の算術平均は使わない**（上記重み合成のみ）。

## 弱い要因の引きずり（全軸共通・合成後）

```
min = 4要因または2要因の最小点
合成 = 重み付き合成点

if min <= 6.0:
  最終 = min(合成, min + 1.5)
elif min <= 7.0 かつ (max - min) >= 2.0:
  最終 = min(合成, round(合成×0.85 + min×0.15, 1))
else:
  最終 = 合成
```

1要因だけ極端に弱いとき、主軸をその要因に引きずる（五軸定義 §2.1 と整合）。
