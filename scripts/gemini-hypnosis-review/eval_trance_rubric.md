# トランス度採点ルーブリック（Gemini 評価脳用・リポジトリ正本）

## 手順（必須順）

1. **トランスレーン（型）を1つ決める**（下表5種）
2. **4次元**を Whisper 根拠付きで 0.0〜10.0（0.1刻み）
3. **レーン別重み**で合成 → 最終トランス度
4. **同レーンのアンカー3本**と位置関係を1文

**採点の根拠:** **注意の誘導・段階づけ・暗示の学習**など既知の仕組みで測る。催眠音声は技法の積み重ねによる物語。評価文の「限定的」「浅い」一言だけで技法スタックを否定しない（`trance_scoring_guards.py`）。

**禁止:** 長さ＝深さ、従順＝深さ、快感＝深さ。戻し・解除は満足度側（ここでは採点しない）。

**性癖中立（必須）:** NTR・女体化・凌辱・輪姦など**題材そのもの**を理由に上げ下げしない。測るのは**催眠体験の品質**（誘導・深化・暗示・維持）のみ。「題材が過激だから没入が浅い」等の推測減点は禁止 — 減点は必ず Whisper 上の**設計の欠け**（誘導が薄い・深化手順が無い等）で根拠づける。減点文から題材名を除いても成立しない減点は書かない。

## 4次元

| 次元 | 見ること |
|------|----------|
| **入り** | 乗れるか（ラポール・CF迂回・入口の丁寧さ） |
| **深さ** | 変性意識としてどこまで沈むか（往復深化・夢混線・無意識寄り） |
| **暗示の効き** | 言葉が体・感覚・行動に刺さるか（カウント・転換・止めて／触って） |
| **維持** | 本編を通して受容状態が崩れにくいか |

**深さの注意（レーン共通）** … 興奮の「真っ白」「ビリビリ」は深化根拠にしない。報酬・支配が本編大半なら **深さ 7.5 以下**を第一候補（T2・T3・T5）。

### 要素欠如時の点数帯（2026-06・必須）

**各次元は「その次元の催眠要素」があるかだけを見る。** エロが強い・耳責めが気持ちいいは**トランス加点に使わない**。

| 次元 | **0.0〜1.0**（要素がほぼない） | **1.0〜2.0**（断片のみ） |
|------|-------------------------------|---------------------------|
| **入り** | リラックス・委ねの一言も無い | 「リラックス」「身を任せて」程度が数分で終わり、深化に繋がらない |
| **深さ** | 多段深化・往復・夢混線・無意識寄りの作劇が**読み取れない** | ぼーっと／ほてりの描写だけで深化手順が続かない |
| **暗示の効き** | 催眠暗示（カウント・再深化・意識分離・反応制御）が**無い**（エロ命令のみ） | 断片的な身体感覚暗示のみ |
| **維持** | トランス状態の維持・再深化が**無い**（興奮・快感の継続だけ） | 脱力の促しが散発するが、半覚醒維持等は無い |

**`minimal` ＋ 報酬・RP主 ＋ 上表の「要素なし」が複数** … 各該当次元は **0.0〜1.0** を第一候補。合成 **2.0 超は原則禁止**（`trance_scoring_guards.py` が自動補正）。**8.0 台は構造的にあり得ない。**

**比較:** `saimin-shinri-test-dame-iwakareru` は旧物差しでトランス 3.0 だが、本帯（要素欠如）では **入り断片 1〜2／他 0〜1 → 合成 約 0.5〜1.5** が妥当。

## 5レーン（トランスの約束）

| ID | 名称 | いつ使うか |
|----|------|------------|
| `deepening` | 深化型 | 深く沈むこと自体が主役。往復・多段深化が芯 |
| `acceptance` | 受容・支配型 | 委ねる・従う・支配下で反応。マゾ・行動制御が芯 |
| `sensory` | 感覚・ASMR型 | 耳・触覚増幅経由の没入が芯 |
| `trigger` | トリガー型 | 特定語・音・反復フックの条件付けが芯 |
| `minimal` | 薄い催眠型 | 催眠体裁のみで誘導が薄い。報酬・RPが主 |

**レーン誤選択の再発防止（必須）**

| 見た目 | 正しいレーン | 誤りやすいレーン |
|--------|--------------|------------------|
| 導入数分で性的命令・耳責めが本編の大半 | **`minimal`** | acceptance（支配＝トランスと混同） |
| 360°耳責め・吐息で没入、深化往復は薄い | **`sensory`** または **`minimal`** | acceptance |
| 委ね・従属＋**再深化・半覚醒・カウント**が本編を貫く | `acceptance` | — |

**`暗示の効き` の見分け（混同禁止）**

- **加点する** … カウント、再深化、意識／無意識の分離、変性意識の維持、夢混線、止めて／触れない等の**催眠的**反応制御。
- **トランス点にそのまま載せない** … 「イッていいよ」「セックスしよう」等の**エロ命令が刺さる**こと。それは**快楽度**側（C-0・刺激・報酬）。
- eval の「深さ」根拠に **多段深化が読み取れない／本編の大半が性的命令のみ** など**技法欠如が明示**され、かつカウント・感覚転移等の積み重ねも無いときだけ、**`minimal`** と要素欠如帯（0〜1）を検討する（`trance_scoring_guards.py`）。
- **禁止:** 「限定的」「浅い」など**注釈の一語だけ**で薄い催眠と判定しない。催眠は物語の積み重ね。後半が快楽パートでも、導入〜深化に技法があればレーンを維持する。

副レーンは付けない（迷ったら **主レーン1つのみ**）。

## レーン別重み（合成式）

```
最終 = round(入り×w1 + 深さ×w2 + 暗示の効き×w3 + 維持×w4, 1)
```

| レーン | 入り | 深さ | 暗示の効き | 維持 |
|--------|------|------|------------|------|
| deepening | 0.20 | **0.35** | 0.20 | 0.25 |
| acceptance | **0.25** | 0.20 | **0.30** | 0.25 |
| sensory | **0.25** | 0.15 | **0.30** | **0.30** |
| trigger | 0.20 | 0.20 | **0.35** | 0.25 |
| minimal | 0.25 | 0.25 | 0.25 | 0.25 |

**T5 minimal** … 各次元点自体を厳しめ（単独9超は要明示根拠）。合成7超も慎重。
