# 快楽度採点ルーブリック（Gemini 評価脳用）

## 手順（必須順）

1. **快楽C-0（快感の約束）を1つ決める**（下表。複合なら主1つ）
2. **4次元**を Whisper 根拠付きで採点
3. **C-0別重み**で合成 → 最終快楽度
4. **既決トランス度を超えない**（トランスありき）

**性癖中立（必須）:** NTR・女体化・凌辱・輪姦など**題材そのもの**で上げ下げしない。測るのは**その作品が売る快感（C-0）に対する刺激設計の品質**のみ。背徳感・屈辱・喪失が快感の燃料として機能しているなら（NTRの寝取られる痛み等）、それは**加点方向の刺激設計**として評価する。「聴き手を選ぶ」「不快に感じる人がいる」は減点理由にしない。減点は反復の単調さ・C-0との矛盾・山の空振り等、**設計の語彙**で根拠づける。

---

## 快楽C-0（5種＋その他）

| ID | 名称 | 一行 |
|----|------|------|
| `brain` | 脳イキ寄り | 頭側・思考停止・心象の飽和が主 |
| `emotional` | 情緒・幸せ寄り | 安心・恋愛・肯定と快感が同位相 |
| `corruption` | 堕落・背徳寄り | ダメなのに・支配・羞恥が報酬 |
| `dry` | ドライ寄り | 射精以外ルートの絶頂が主 |
| `trigger` | トリガー寄り | 特定語・音・パターンへの条件反射 |
| `other` | その他・複合 | 上記の併記（寸止め・カウント絶頂等） |

詳細成功定義は `docs/レビュー三軸評価定義.md` C-0 を参照。

---

## 4次元

| 次元 | 見ること |
|------|----------|
| **コンセプト整合** | C-0と本編（台詞・パート配分）が矛盾しないか |
| **刺激・報酬** | 感覚描写・反復・条件付けの筋道 |
| **クライマックス** | 絶頂・山の設計・回収（ウェット/ドライの区別） |
| **起伏・焦らし** | 寸止め・禁止・カウント等のドーパミン起伏 |

## C-0別重み

| C-0 | 整合 | 刺激 | クライマックス | 起伏 |
|-----|------|------|----------------|------|
| brain | 0.25 | 0.30 | 0.25 | 0.20 |
| emotional | 0.30 | 0.25 | 0.20 | 0.25 |
| corruption | 0.25 | 0.25 | 0.25 | 0.25 |
| dry | 0.30 | 0.30 | 0.25 | 0.15 |
| trigger | 0.20 | 0.35 | 0.25 | 0.20 |
| other | 0.25 | 0.25 | 0.25 | 0.25 |

**トランス上限:** 既決トランス度 + 1.5 を超える快楽度は要例外理由。通常は **快楽 ≤ トランス + 1.2** 目安。
