# Gemini 出力キー（シチュエーションボイス・厳守）



**このファイルのキー以外を出力しない。Markdown の `## 作品名` 等の見出し・クイック解析形式は禁止。**

**正本:** `docs/シチュエーションボイス執筆ガイド.md`（催眠の四表・誘導の流れ・体験感度Lv・三軸キーは**出力しない**）。



**文体:** `設計` `導線` `手順` `固定`（台詞引用 `> ` のみ可）・`立ち上が` 系・`芯`（メタ）を読者向け散文で使わない。
