# 催眠レビュー解析 暫定フォーマットメモ

このファイルは、チャットで確定した暫定運用を保存するためのメモ。
正式運用は後日 `docs/真催眠音声執筆ガイド.md` へ反映する。

## 1. 集計対象の原則

- 解析対象は基本的に本編中心。
- 指示がある場合、`01 注意事項`、`02 レクリエーション`、`05 解除` を除外して集計する。
- 除外条件は本文と JSON の両方で明記する。

## 2. 誘導分析（Induction）

- 5カテゴリを使用し、合計値は `10` に正規化する。
  - 論理性
  - 強制力
  - 突破力
  - 浸透力
  - 身体性
- 項目表示は「カテゴリ + 技法表記」。
  - 技法は `【】` で括る。
  - 複数技法は `/` ではなく、`【技法1】` `【技法2】` のように分割して改行。

## 3. 暗示分析（Suggestion）

- 7属性を使用し、合計値は `10` に正規化する。
  - 感覚暗示
  - 認知暗示
  - 反応暗示
  - 関係性暗示
  - トリガー暗示
  - 否定暗示
  - 時間歪曲暗示
- 未使用要素は `0` で出力してよい。
- 表示は誘導と同じく「カテゴリ + `【】` 技法分割」で統一する。

## 4. 特性スコア（独立評価）

- 誘導特性・暗示特性は、各項目を `5` 点満点で独立評価する。
- 作品ごとに都度算出し、過去作品の特性値を流用しない。
- 判定時は「一部抜粋」ではなく、全特性を総括して判断する。
- 新規特性が有意な場合は進言し、追加して出力する。

## 6. Lv規定（固定）

- Lv1: トランス感覚がまだ掴めない
- Lv2: 浅いトランスは可能（重感・脱力まで）
- Lv3: 中程度トランス＋暗示受容は可能（ただし絶頂反応は未形成）
- Lv4: 脳イキは可能だがドライ未達
- Lv5: 脳イキ・ドライとも可能（再現性あり）

## 7. Lv表示ルール（本文）

- 全作品で「体験可能レベル = 推奨レベル」を採用する。
- 本文表示は `推奨感度Lv` のみを出す。
- 例:
  - `推奨感度Lv：3以上`

## 8. 本文の見出し・配置（現行）

- 強調対象見出し:
  - 作品概要
  - 作品評価グラフ
  - 本作の誘導・暗示解析
  - 解析まとめ
- 構成比テーブルの列見出し:
  - `項目`
  - `数値`
  - `読者が得る体験`
- 構成比注記文（最新）:
  - 誘導構成比:
    - ここではどのような技法を用い催眠誘導しているかを可視化しています。
    - 解除パート等を除外した本編のみの比率です。
    - 数値は割合を表していて合計10になります。
  - 暗示構成比:
    - ここではどのような暗示を用いリスナーに快楽体験をさせるかを可視化しています。
    - 解除パート等を除外した本編のみの比率です。
    - 数値は割合を表していて合計10になります。

## 9. 保存運用

- 作品ごとに `誘導分析メモ.json` を保存。
- 横断用に `_誘導分析データ一覧.json` を更新。
- テンプレは `docs/催眠誘導分析テンプレート.md` を使用。
