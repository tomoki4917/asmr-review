# 全年齢シチュエーションボイス — 五軸評価定義（正本）

**用途:** 全年齢シチュエーションボイス（R18表現が主目的でない同人音声）レビューの **五軸採点** と **`グラフ評価内訳`** の物差し。  
**執筆ガイド:** `docs/全年齢シチュエーションボイス執筆ガイド.md` と併用する。  
**注意:** 現行の `_分析データ.json` v2 スキーマ互換のため、数値キーは `pleasure` を流用しつつ、**読者向け表示名は `睡眠・覚醒`** として扱う（`radarAxisLabels.pleasure: "睡眠・覚醒"` を併記してよい）。

---

## 1. 五軸の意味（主軸）

| キー（v2互換） | 表示名 | 何を測るか |
|------|--------|------------|
| `scenario` | **シナリオ** | 物語・関係・台詞・作品の「約束」が、聴取中に破綻せず機能しているか |
| `acoustic` | **音響** | 録音・ミックスとして、台詞と情景音が聴き取りやすく競合していないか |
| `immersion` | **没入度** | 音像と距離感で、耳と意識が作品の場に入りやすいか |
| `pleasure` | **睡眠・覚醒** | **入眠のしやすさ**（落ち着き・安心・テンポ）と、必要なときの**覚醒の気持ちよさ**（起き上がり・リセット・余韻）を、音声作品として回収できているか |
| `satisfaction` | **満足度** | 聴き終わったとき、販売の約束が回収され、終端が気持ちよいか |

**採点順（ありき）:** シナリオ → 音響 → 没入度 → 睡眠・覚醒 → 満足度 → `ratingValue`（★は五軸の**平均禁止**）。

**根拠:** 再生音声（本編）のみ。フリートーク・NG集・メイキングは五軸に含めない。

---

## 2. 採点方式（表示はサブ項目なし）

**サブ項目（例: リアリティ / 展開の必然性）で採点しない。**  
読者向け `グラフ評価内訳` は、各軸を **主軸1点のみ**で扱う。

### 2.1 睡眠・覚醒以外の4軸

**シナリオ / 音響 / 没入度 / 満足度** は、  
`docs/シチュエーションボイス執筆ガイド.md` の採点方式（§3・§4）をそのまま使う。

### 2.2 睡眠・覚醒（全年齢専用）

`睡眠・覚醒` は全年齢専用の追加軸として、次の観点だけで主軸1点を決める。

- 入眠しやすいか（落ち着き・安心・テンポ）
- 終端のリセットが気持ちいいか（眠りへ落とす / 心地よく起こす）

**注意:** 快感の派手さを理由に上げない（R18の尺度を混ぜない）。

### 2.3 シナリオの内部評価観点（内部メモのみ）

分割採点は表示しないが、シナリオ主軸を決める際は内部メモとして次を確認してよい。

- 空間と心理の生々しさ（場面の空気が音声で立つか）
- 作品内の一貫性（呼称・立場・時系列の矛盾）
- ギミックの機能（タイトルの仕掛けが進行に効くか）
- 導入と転換の独自性（一本として記憶に残るか）

※ これらは**内部判断用**であり、`グラフ評価内訳` に小見出しとして出さない。

---

## 3. 数値の付け方（0.1刻み）

帯の目安・比較アンカー・★10の扱いは `docs/シチュボイス五軸評価定義.md` と同じ。

---

## 4. グラフ評価内訳 — 表示形式（読者向け）

### 4.1 軸行

括弧内のサブ点数は出さない。

```markdown
- **睡眠・覚醒 8.8**
```

**NG 例（禁止）**

- 軸行の後ろに括弧で補助点を併記する形式（`（A / B）` など）
- 1軸を二段の小見出しに分ける形式

### 4.2 軸ごとの根拠文（サブ項目なし）

並び: **シナリオ → 音響 → 没入度 → 睡眠・覚醒 → 満足度**。

| 文 | 役割 |
|----|------|
| **1〜2文目** | 主軸1点の根拠（加点理由・作中の事実） |
| **最終文** | **伸びしろ** |

- **1軸あたり 2〜3文・合計 120〜200字**目安
- **サブ項目名を `**太字見出し**` で並べない**
- **五軸の数値はこのブロックだけ**
- **軸名は固定**（シナリオ／音響／没入度／睡眠・覚醒／満足度）
