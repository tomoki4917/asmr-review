## 距離感（distance）・低音ボイス／近接効果（v0.2.1）

**問題** … 至近の低音ボイス（地声低めの女性声優等）では、近接効果で **100–250Hz** が増え **4kHz+ が相対的に伸びにくい**。`hf_ratio ≥ 0.2` だけだと密着を過小評価しうる。

**二系統判定（`proximityCloseSignature`）**

| 経路 | 条件 | 意味 |
|------|------|------|
| HF（従来） | `hf_ratio_ge_4khz` 平均 ≥ 0.2 | 高域・息多めの近接囁き |
| LF 強 | `lf_ratio_100_250hz` 平均 ≥ 0.10 | 低音域エネルギー優位（近接効果） |
| LF＋低centroid | LF ≥ 0.055 かつ centroid ≤ 3200 Hz | 低音ボイス密着 |
| LF＋超低centroid | LF ≥ 0.045 かつ centroid ≤ 2600 Hz | より低い声質 |

終盤トラック加点も **centroid > 4200** に加え、上記 LF 経路を同等扱い。

**データ源** … `spatial_spectral.auto.json`（`analyze_mp3_immersive_metrics.py` が LF 帯を出力）。再生成後に `review:score-doujin-graph` を実行。

## マイク・録音品質（recording）・クリップ減点免除（v0.2.2）

**問題** … 至近の息吹き・耳舐め・吸音区間では RMS が飽和しやすく、`clip_ratio_mean > 0.015` で一律 **-1.5** すると「臨場感のための過負荷」をノイズと誤判定しうる。

**二段判定（`assessClipRecordingAdjust`）**

1. **時間軸照合** … 各トラックで waveform のクリップ相当フレーム（RMS > 98% max）が、Whisper/SRT 上 **近接 SFX 語**（`PROXIMITY_SFX_LEX`：`ふぅ` `んちゅ` `レロ` `ぐちゅ` 等）を含む字幕区間と重なる割合 → `clip_sfx_overlap_ratio`
2. **語密度** … 全尺あたりの SFX 語ヒット数 → `sfx_density_per_min`

| 条件 | 扱い |
|------|------|
| `clip > 0.015` かつ overlap ≥ 0.5 **または** sfx/min ≥ 0.8 | **減点免除**（`clip_proximity_sfx_exempt`） |
| 上記に加え sfx/min ≥ 1.2 **または** overlap ≥ 0.65 | **+0.35**（`clip_proximity_sfx_bonus`） |
| `clip > 0.05` かつ sfx 文脈なし（sfx/min < 0.4 かつ overlap < 0.35） | **-1.5 維持**（破損マスタ疑い） |
| それ以外の高 clip | **-1.5**（従来どおり） |

**限界** … Whisper が息・擬声を書かない区間は overlap が効かない。公開確定採点は引き続き**音声聴取**が主根拠。
