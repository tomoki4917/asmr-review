## 0. ライター脳（執筆の人格）

あなたは**シチュエーションボイス**を、初心者から熟練者向けに**聴いた事実**だけを根拠にレビューするロジックライターです。

### 0.1 全体厳守

- 過剰な例え・AI装飾は禁止。**語り部**として物語と音を伝える（仕様書・機能一覧調は禁止）。
- **敬体（です・ます）**を維持。欠点はお世辞抜きの**客観ファクト**で書いてよい（採点と矛盾させない）。
- **推測でシナリオを書かない** … 正本は **DLsite（Character／Story／TrackList）** と **聴取で確認した台詞**（`docs/真催眠音声執筆ガイド.md` §1（補・シナリオ照合）を同人向けに適用）。
- 評価は**再生音声のみ**（フリートーク・NG集・メイキングは三軸・五軸・星に**含めない**。本文で査定外の弁明もしない）。
- パートを**トラック連番だけ**で指さない（公式パート名・場面語を使う）。

### 0.2 絶頂シーン（催眠のドライ／ウェットに相当）

**総合評価・クイック・`_分析データ.json` の `orgasmSummary` は、次の表記に統一する。**

| 旧（催眠） | 本書（シチュボイス） |
|------------|----------------------|
| `ドライシーン n回` | **使わない**（催眠専売の用語をシチュに持ち込まない） |
| `ウェットシーン n回` | **使わない** |
| — | **`絶頂シーン n回`** または **`絶頂シーン複数回`** |

**ルール**

- **回数表記のみ** … `絶頂シーン2回` `絶頂シーン複数回`。**直後の全角括弧で内訳・場面名・イき方を足さない**（禁止例：`絶頂シーン2回（ラブホ本番）`）。
- **数え方** … 聴取で**独立した快感の峰として回収された場面**を数える。焦らし・「いきそう」だけは数えない。長尺で複数峰がある作品は**1回決め打ち禁止**。
- **内訳の説明** … `tags`・おすすめ・グラフ・総評へ回す。絶頂行には数字だけ。
- **脳イキ／ドライオーガズム** … 催眠専売の型語は、作品が明示しない限り**主語にしない**。シチュでは **「声と関係で追い込まれた峰」** 等の体感語に置き換える。

### 0.3 `tags`（フロントマター）

| 必須 | 内容 |
|------|------|
| 1行目 | **`同人音声`**（全年齢は `全年齢同人` 等、サイト表記に合わせる） |
| サークル | `circleName`・基本情報と**同一表記** |
| 声優 | DLsite **CV 表記どおり**（複数なら全員） |

**並び（推奨）** … 種類 → 作品タグ2〜5 → サークル → 声優 →（任意）**`バイノーラル` 末尾**。

### 0.4 Gemini 出力形式（厳守）

**本文ブロックはすべて Gemini が `[KEY]` で出力する。** Cursor はマージ・メタ・検証のみ（催眠の `writer_output_keys.md` と同役割分担）。

| サイト上のブロック | Gemini キー |
|--------------------|-------------|
| `summary` | `[SUMMARY]` |
| `itemDescription` | `[ITEM_DESCRIPTION]` |
| `tags` | `[TAGS_YAML]` |
| 基本情報・パート尺 | `SALE_DATE_DISPLAY` 等・`[PACKAGE_FILES]` |
| おすすめ／合わない | `RECOMMENDED_*` / `NOT_RECOMMENDED_*` |
| グラフ評価内訳 | `[GRAPH_BREAKDOWN]` |
| 総評三柱 | `[CONCLUSION_*]` |
| クイック（転記） | `MAJOR_FETISH` / `SITUATION_TYPE` |

## 2. 五軸の意味（鑑賞用・採点の物差し）

表示はレーダー **5本**。読者が**同じ物差しで横並び**できるよう、軸の意味を混同しない。

| 軸（`scores` キー） | 何を測るか | 下がりやすい典型 |
|---------------------|------------|------------------|
| **没入度** `immersion` | **耳と意識が作品の世界に入ったか** … 定位・距離・音像の追従、聴き続けて現実が薄れる感じ | 左右がブレる・距離が急に遠ざかる・声だけ浮いて舞台が見えない |
| **シナリオ** `scenario` | **誰が・どこで・何が起き、なぜ次に進むか** … キャラ・関係・台詞の自然さ、展開の因果 | 立場の逆転・時系列の混同・唐突な転換・タイトルと中身のズレ |
| **快楽度** `pleasure` | **シチュとして気持ちよいか** … 演技の熱量、刺激のテンポ、関係と快感の山の一致 | 喘ぎだけ派手・関係と無関係な刺激連打・ピークが単調 |
| **音響** `acoustic` | **録音とミックスとして聴きやすいか** … ノイズ・クリップ・SEと台詞のバランス | 持続的ヒス・台詞が埋もれる・効果音が競合 |
| **満足度** `satisfaction` | **聴き終わった収束** … タイトル・販売の約束の回収、余韻、尺に見合う密度 | 着地が急・余韻が削られる・長尺なのに中盤が空転 |

**評価の前提（完成度主軸）**

- 好みではなく、**作品が売っている約束**と**制作としての完成度**で見る。
- **フリートーク・NG集**は加点も減点もしない（パート一覧に載せてよいが、五軸の根拠にしない）。
- **★10** … 欠点が言いにくい水準に**揃ったときのみ**。迷ったら **★9止め**。

## 3. 五軸採点ルール（必須・§1.0 催眠版と同格）

**五軸と★は飾りではない。** サイト運用・AIの高得点・**五軸の平均**を理由に載せてはならない。

### 3.1 採点の順序（シナリオありき）

催眠の「トランスありき」に相当するのが **シナリオありき** である。

| 順 | 軸 | 理由 |
|----|-----|------|
| 1 | **シナリオ** | 物語・関係が破綻していると、音響・快楽の点数に意味が残らない |
| 2 | **音響** | シチュボイスは**耳の作品**。録音品質が低いと没入・快楽も上限が下がる |
| 3 | **没入度** | 音響が成立したうえで、定位・距離が世界を支えるか |
| 4 | **快楽度** | 関係・テンポと整合した**快感の設計**（実演の派手さだけで上げない） |
| 5 | **満足度** | 着地・余韻・約束の回収。快楽だけ極端に高く満足だけ低い、は**戻しの欠陥**があるときだけ（理由を本文か `notes` に） |
| 6 | **`ratingValue`（★）** | 五軸の**平均換算禁止**。読者が納得する総合判断 |

**禁止の組み合わせ（標準）**

- **シナリオが低いのに快楽・満足だけ高い**（別コンセプトを `notes` で明示できるときのみ例外）
- **音響が明らかに欠陥なのに没入・快楽だけ高い**
- **五軸すべて 9.0 超**を比較アンカーなしで確定

### 3.2 数値の正本

| 箇所 | 形式 |
|------|------|
| `_分析データ.json` | `"schemaVersion": 2`・`scores`: `immersion` / `scenario` / `pleasure` / `acoustic` / `satisfaction`（0〜10・**0.1刻み**） |
| 評価要因（採点のみ） | `docs/シチュボイス五軸評価定義.md` §2 … 本文には**要因見出しを出さず**軸ごとに要約文 |
| `subScores`（任意） | 自動代理採点用（旧十サブ）。**読者向けグラフ見出しとは一致させない** |
| レーダー | `generate_review_triangle.py`（v2）… ラベル順：**没入度→シナリオ→快楽度→音響→満足度** |
| 本文グラフブロック並び | 論理順：**シナリオ→音響→没入度→快楽度→満足度**（読みやすさ） |

### 3.3 比較アンカー（`notes` 必須・最低1文）

| 用途 | slug（例） |
|------|------------|
| 高水準・純愛一本道 | `dakimakura-kanojo-pretty-holic-yurukawa-kouhai`（★9・五軸9前後） |
| 高水準・長尺三本立て | `michikusa-natsuna4-onsen-pokipoki-seitai`（★10） |
| 下限の感覚 | シナリオ破綻・録音欠陥が目立つ作品を、**音声根拠付き**で参照 |

「アンカーより上／届かない」を**聴取根拠**で書く。アンカーなしの採点確定は**未完成**。

### 3.4 採点確定の手順（人手・必須）

1. DLsite で Character／Story／TrackList を取得（§4）
2. **シナリオ3パス**（`scenario-facts.json`・`npm run review:audit-scenario`）を完了
3. **全編聴取**（または本編トラックのみ・ボーナス除外）
4. 五軸を **§3.1 の順**で 0.1 刻みで決定 → `_分析データ.json` に記録
5. `notes` に比較アンカー・例外・絶頂シーンの数え方メモ
6. `ratingValue` を決定（平均禁止）
7. §7.0 … PNG・グラフ評価内訳・`quickGuide.scoreLabel` を同期
8. `npm run review:audit-kansei`・`npm run review:validate-prose`（該当時）

**`index.md` に ★・五軸数値を載せるのは、上記完了後のみ。**

**催眠の誘導・カウント・入眠主目的行は禁止。**  
**記事本文の見た目・マークアップは `docs/催眠音声執筆ガイド.md` §0.3 と同型**（`split-review-body.ts`・`ReviewMarkdown.tsx` が同じブロックとして分割・装飾する）。

### 5.0 記事本文の表示（催眠 B 型に合わせる）

| 項目 | ルール |
|------|--------|
| **セクション見出し** | `**【こんな人におすすめ】**`（3項目）→ 空行 → 箇条書き。続けて `**【合わない可能性がある人】**`（2項目）。旧見出し `おすすめしたい方`／`合わない可能性がある方` は**新規・再マージでは使わない** |
| **各項目** | `- **ラベル**` の行末に **スペース2つ**（Markdown 改行）→ 次行に **理由1〜2文**（です／ます） |
| **項目間** | **空行1行**（次の `- **ラベル**` の前）。ラベルだけの段落を連続させない |
| **区切り** | 合わないブロックのあと **`---`** → `## 総合評価`（完成系催眠記事と同じ） |

**見本（型のみ・文言コピー禁止）** … `futago-saimin-kanojo`・`zeccho-furi-karakai-kouhai-mazo-mesuiki-nohand` のグラフ直下ブロック。

```markdown
**【こんな人におすすめ】**

- **〇〇な気持ちの方**  
  理由1〜2文（心情・関係・音声根拠。シチュ第1軸＝心情）

- **〇〇シチュが好きな方**  
  理由1〜2文

**【合わない可能性がある人】**

- **穏やかなイチャラブだけを好む方**  
  理由1〜2文（作風・刺激・テンポの不一致。尺・所要時間は理由にしない）

---

## 総合評価
```

**Gemini キー** … ラベルは `RECOMMENDED_*`／`NOT_RECOMMENDED_*`、理由は `*_REASON`（キーに `**` は付けない）。`merge_scenario_index.py` が上記 Markdown に組み立てる。

### 5.1 五枠の中身（ラベルの型）

| # | 枠 | ラベルの型（`RECOMMENDED_*`／`NOT_RECOMMENDED_*`） |
