# 催眠誘導分析テンプレート

催眠音声レビュー向けの保存テンプレート。  
目的は「作品ごとの比較」「ランキング集計」「再分析時の差分追跡」。

## 保存ルール

- 各作品フォルダに `誘導分析メモ.json` を保存する。
- スコアは `5カテゴリ合計10` と `システム特性(各5点独立)` を併記する。
- 暗示分析を行う場合は `7属性合計10` と `暗示システム特性(各5点独立)` を追記する。
- 除外条件（注意事項/レクリエーション/解除など）は必ず明記する。
