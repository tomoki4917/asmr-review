# シチュエーションボイス — 五軸評価定義（正本）

**用途:** 同人シチュエーションボイスレビューの **五軸採点** と **`グラフ評価内訳`** の物差し。  
**執筆ガイド:** `docs/シチュエーションボイス執筆ガイド.md` §3・§7 と併用する。  
**催眠三軸・誘導深度・トランス前提の物差しは使わない。**

---

## 1. 五軸の意味（主軸）

| キー | 表示名 | 何を測るか |
|------|--------|------------|
| `scenario` | **シナリオ** | 物語・関係・台詞・作品の「約束」が、聴取中に破綻せず機能しているか |
| `acoustic` | **音響** | 録音・ミックスとして、台詞と情景音が聴き取りやすく競合していないか |
| `immersion` | **没入度** | 音像と距離感で、耳と意識が作品の場に入りやすいか |
| `pleasure` | **快楽度** | シチュとして気持ちよいか（演技・テンポ・関係と峰の一致） |
| `satisfaction` | **満足度** | 聴き終わったとき、販売の約束が回収され、終端が気持ちよいか |

**採点順（ありき）:** シナリオ → 音響 → 没入度 → 快楽度 → 満足度 → `ratingValue`（★は五軸の**平均禁止**）。

**根拠:** 再生音声（本編）のみ。フリートーク・NG集・メイキングは五軸に含めない。

---

## 2. 評価要因（採点の内側・読者向けには見出しを出さない）

各主軸は、下表の **評価要因** で**採点・Gemini eval**する。読者向け `グラフ評価内訳` には **要因名の見出し（例: 心理・空間の生々しさ）を書かない**。軸行のあと **2〜3文**で、要因を**要約して織り込んだ根拠**だけを書く。

### 2.1 シナリオ（4要因）

ユーザー提案をベースに、**「学校リアルか」一辺倒のリアリティ**と**「因果の一本道」だけの必然性**に寄りすぎないよう再定義した。

| 要因 | 見ること | 高いとき | 低いとき |
|------|----------|----------|----------|
| **心理・空間の生々しさ** | その場所・その関係の**空気**が台詞と間で立つか。心情が「説明」ではなく**聴いてわかる**か | 生徒会室／自宅／浴室など、場面ごとに距離と緊張が変わる。照れ・焦り・甘さが生きている | 台詞だけ流れ、舞台が見えない。感情が型どおりで薄い |
| **世界観の内的一貫性** | 作品内ルール（立場・呼称・口調・時系列）が**通しで矛盾しない**か | 後輩→恋人の段階と声色・距離がずれない。DLsite Character と逆の関係にならない | 呼称ブレ・立場逆転・プロローグと本編の時系列混乱 |
| **ギミックの機能性** | タイトル・販売が売る**芯の仕掛け**（抱き枕・寝取り・治療・逆転 等）が、各パートで**進行のエンジン**になっているか | 仕掛けが「飾り」ではなく、接触の種類・関係の深さを変えていく | ラベルだけで中身が汎用R18。仕掛けを外しても同じ話になる |
| **フックの独自性** | 冒頭・タイトルの**約束**が他作品と被らず、聴後も「この一本」と言えるか | 導入の一言が印象に残り、関係の転換点（告白・同居 等）と結びつく | テンプレ導入。タイトルと中身のズレ。差別化が声優名だけ |

**主軸 `scenario` の決め方:** 4要因を聴取後に **`eval_scenario_rubric.md` のレーン別重み**で合成する。**4要因の算術平均は使わない**。1要因だけ極端に弱いときは **弱い要因引きずり**（合成 ≤ min+1.5 等）で主軸を引きずる。

---

### 2.2 音響（2要因）

| 要因 | 見ること |
|------|----------|
| **台詞の明瞭さ** | 囁き・密着・キス音が多くても**声が前景**に残るか。ヒス・クリップ・トラック間の音量崩れ |
| **情景音と静寂の配分** | 水音・布擦れ・BGMが**台詞を殺さず**、場面（室内／風呂 等）と一致しているか |

**連動:** シナリオが大きく破綻しているのに音響だけ満点にしない。

---

### 2.3 没入度（2要因）

| 要因 | 見ること |
|------|----------|
| **定位の追従性** | 左右・前後の移動が**意図的に追える**か。通しで定位基準が大きく崩れないか |
| **親密距離の持続** | 耳元・添い寝・密着で売る**近さ**が、終盤まで音で維持されているか |

**連動:** 音響欠陥（台詞不明瞭）があるのに没入だけ高くしない。

---

### 2.4 快楽度（2要因）

| 要因 | 見ること |
|------|----------|
| **声色の関係連動** | からかい→照れ→恋人 等、**関係の段階と声色が同期**するか。オホ声だけで熱量を賄っていないか |
| **峰と間の配分** | 焦らしと絶頂の置き方が**関係の山と同じタイミング**か。同型の刺激連打・間延び |

**禁止物差し:** 暗示の届き方・トランス深度・脳イキ／ドライ型の催眠用語を主理由にしない。

---

### 2.5 満足度（2要因）

| 要因 | 見ること |
|------|----------|
| **売り文句の回収** | タイトル・Story・タグの約束が本編で**薄まらない**か |
| **終端の気持ちよさ** | パート終わり・本編終わりが**急断ちしない**か。就寝導線と本編の熱量が矛盾しないか |

**【安眠用】等:** 着地・終端要因に反映してよいが、`summary`・グラフ・総評に**ラベル名と説明は書かない**（`### パートの長さ` の公式名・尺列挙のみ可）。

---

## 3. 数値の付け方（0.1刻み）

| 帯 | 目安 |
|----|------|
| **9.0〜10.0** | その軸の要因を聴いて、**欠点を言いにくい**（★10は五軸全体が揃ったときのみ） |
| **8.0〜8.9** | 完成度高いが、要因のどれかに**はっきりした伸びしろ**がある |
| **7.0〜7.9** | 楽しめるが、要因の弱さが**聴取で確認できる** |
| **6.9以下** | 軸として**作品の売りを損なう**欠陥が目立つ |

**比較アンカー（`notes` 必須）**

- 高水準・一本道: `dakimakura-kanojo-pretty-holic-yurukawa-kouhai`
- 高水準・長尺: `michikusa-natsuna4-onsen-pokipoki-seitai`

## 4. グラフ評価内訳 — 表示形式（読者向け）

### 4.1 軸行

**括弧内のサブ点数は出さない。**

```markdown
- **シナリオ 8.8**
```

### 4.2 軸ごとの根拠文（要因を要約・見出しなし）

並び: **シナリオ → 音響 → 没入度 → 快楽度 → 満足度**。

```markdown
- **シナリオ 8.8**
  生徒会室から自宅・ラブホへ場面が移るたび、台詞と間で関係の温度が変わり、抱き枕から恋人へ一本道が破綻なく続きます。枕役の仕掛けが接触の段階を変え、導入の一言も印象に残ります。情景だけでは空気が薄い瞬間があり、先輩側の内面は浅めで、物語の厚みはもう一段欲しいです。
```

| 文 | 役割 |
|----|------|
| **1〜2文目** | §2 の要因を**見出しにせず**織り込む（加点根拠・作中の事実）。シナリオ4要因・他軸2要因を**要約** |
| **最終文** | **伸びしろ**（率直に） |

- **1軸あたり 2〜3文・合計 120〜200字**目安（旧・要因見出し＋各2文の十段落形式は廃止）。
- **要因名を `**太字見出し**` で並べない**（心理・空間の生々しさ、台詞の明瞭さ 等は採点メモ用）。
- **五軸の数値はこのブロックだけ**。
- パートは**トラック連番だけ**で指さない。

### 4.3 旧形式（廃止）

| 廃止 | 理由 |
|------|------|
| `- **シナリオ 9（リアリティ 9 / 展開の必然性 9）**` | 括弧サブ点 |
| **`**心理・空間の生々しさ**` 等の要因見出し** | 読者向けは軸＋要約文のみ |
| 要因ごとの `8.5` などの点数 | 主軸1点のみ |

## 5. `_分析データ.json` との関係

| フィールド | 内容 |
|------------|------|
| `scores` | 五軸の正本（PNG・軸行と**文字列一致**） |
| `scenarioLane` / `scenarioLaneLabel` | シチュレーン ID・表示名（シナリオ軸 eval で決定） |
| `scenarioScoring` … `satisfactionScoring` | 各軸の **要因次元点**・`rubricVersion`（内部監査用。読者向けグラフには出さない） |
| `subScores` | **任意**。自動代理採点（旧十サブ）用。読者向けグラフとは**一致させなくてよい** |
| `notes` | 比較アンカー・採点メモ・絶頂シーンの数え方 |

Gemini 五軸 eval では `notes` に `scenario-v2-four-factor-lane-weighted` を1行書く。採点正本は **`eval_scenario_rubric.md`**（レーン別重み＋弱い要因引きずり）。

## 7. 旧十サブ → 新要因（対応表・移行用）

| 旧サブ（廃止・本文） | 新要因への寄せ方 |
|----------------------|------------------|
| リアリティ | → **世界観の内的一貫性** ＋ **心理・空間の生々しさ**（「現実の学校か」だけで書かない） |
| 展開の必然性 | → **ギミックの機能性** ＋ **フックの独自性** |
| マイク・録音品質 | → **台詞の明瞭さ** |
| 環境音 | → **情景音と静寂の配分** |
| 空間定位・音像 | → **定位の追従性** |
| 距離感・密着度 | → **親密距離の持続** |
| 演技力 | → **声色の関係連動** |
| 刺激のテンポ・緩急 | → **峰と間の配分** |
| コンセプトの達成度 | → **売り文句の回収** |
| 余韻の質 | → **終端の気持ちよさ** |
