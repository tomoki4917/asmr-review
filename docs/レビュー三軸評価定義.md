# アイアン・トライアングル（3軸）評価の定義

レビュー記事の **トランス度（$T_{ie}$）・快楽度（$D_{si}$）・満足度（$H_{er}$）** を数値化するときの共通定義です。  
タイムスタンプ付きの作品データ（波形・主観ログ等）がある場合はそれを優先し、ない場合は本定義に沿った**定性評価**でスコアを決めます（いずれも各軸 10.0 満点）。

---

## 1. トランス度（Trance Induction Efficiency / $T_{ie}$）

**【定義】**  
外界の情報を遮断し、意識が内部（暗示）へ集中する「変性意識状態」の深度。

**脳科学的指標**

- **DMN（デフォルト・モード・ネットワーク）の抑制率**  
  自己参照的な思考を止め、純粋な受容状態にあるか。
- **$\theta$ 波（シータ波）への誘導ポテンシャル**  
  バイノーラルビートや特定の周波数（$4 \sim 7\,\mathrm{Hz}$）による共鳴誘導。

**心理学的指標**

- **ミルトン・モデル（逆メタ・モデル）の密度**  
  曖昧な表現を用いて、聴取者の脳が自発的に意味を補完し、没入する仕組みがあるか。
- **ペーシング＆リーディングの同期性**  
  呼吸速度や瞬きのタイミングに合わせた音響設計の精度。

---

## 2. 快楽度（Dopaminergic Spike Intensity / $D_{si}$）

**【定義】**  
報酬系回路が刺激され、脳内で神経伝達物質がバーストする強度。

**脳科学的指標**

- **側坐核（NAc）の活性推測**  
  期待感（予期快感）と報酬（消費快感）のラグを意図的に作り、ドーパミン噴出を最大化しているか。
- **体性感覚野の共感覚的刺激**  
  音の定位移動（Pan）により、皮膚が実際に触れられていると錯覚する「ASMR トリガー」の有効性。

**心理学的指標**

- **アンカリングの深度**  
  特定のトリガー音と、過去の快感記憶を強固に結びつける「古典的条件付け」の完成度。

---

## 3. 満足度（Homeostasis & Emotional Resolution / $H_{er}$）

**【定義】**  
体験後の多幸感の持続と、自律神経の調整（整い）のレベル。

**脳科学的指標**

- **オキシトシンおよびセロトニンの合成率**  
  興奮（ドーパミン）の後の、安らぎと幸福感（アフターケア）の充実度。
- **副交感神経の優位性シフト**  
  心拍変動（HRV）を安定させ、入眠やリラックスへ導く収束プロトコルの有無。

**心理学的指標**

- **ツァイガルニク効果の解消**  
  物語や暗示が未完了のまま放置されず、脳が「完了した」と認識して深い休息に入れるか。

---

## データファイルとの対応

- レビューごとの数値は `src/content/レビュー/<slug>/_分析データ.txt` に記載する。
- グラフ画像 `review_triangle.png` は `scripts/generate_review_triangle.py` で生成する。

```bash
python scripts/generate_review_triangle.py <slug>
npm run sync:content-assets
```
